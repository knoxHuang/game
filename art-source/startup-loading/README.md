# 启动资源无损优化

这里只转换既有共用图集和面板，不生成或重绘美术。这里保存 PNG 母图备份，运行时改用 `public/assets/game/*.webp` 和 `public/assets/ui/brass-panel.webp`。

压缩命令为 `cwebp -lossless -exact -m 6`。Pillow 验证尺寸和每个 RGBA 字节完全相同；透明像素的颜色也保留。逐项体积与验证见 `compression.json`。大厅四张图另见 `../lobby/loading-optimization/`。

这两组共 11 张大图从 20,772,098 字节降至 16,130,628 字节，减少 22.3%。既有 PNG 保留作参考，运行引用统一改用无损 WebP。

启动阶段由 `STARTUP_ART` 统一声明 13 项图像。进度按真正完成的资源数计算，包括命中缓存的资源。未加载完时不开放首页和调查恢复；请求失败允许重试，仅重新排队缺失资源。成功后再读取存档。副本资源继续按需加载，不把所有地区放到首屏。

浏览器验证截图在 `artifacts/lobby-loading/`。使用隔离地址模拟提灯延迟 12 秒及主角图像持续 HTTP 503；确认进度显示 11/13，失败显示 12/13，恢复网络并重试后进入首页。浏览器模拟检查不能代替 iPhone Safari 真机网络验证。

预加载使用 Phaser 的 `HTMLImageElement` 模式，让大厅 DOM 复用已解码的图片 URL；避免 XHR Blob 预加载后又发起大厅图片请求。隔离慢网服务器记录大厅四个 URL 各请求一次；进入大厅时所有图片均已完成。刷新进行中调查后，生命、经验、升级候选和暂停状态正常恢复。
