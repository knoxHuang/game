# 固定坐标分层立绘

2026-10-16。使用已有项目原创资产与确定性像素蒙版编辑，未调用 ImageGen。已接入角色页与职业展台。

## 制作方式

完整内搭复用 `../posture-fix/linjin-base-before.png`。雨衣、帽子与握帽前景取自 `../linjin-raincoat-reference.png`。两者沿用原有正面偏侧姿势，不生成新人物，也不在运行时拉伸衣服。

本次没有声称从一张穿戴图还原出被挡住的全部内搭。先前将母图可见内搭与另一底图逐块拼接，产生衣片残留、拼接边和手指重影；现在直接保留完整内搭，修正雨衣提取边界，避免在内搭中间制造接缝。

分层顺序为完整人物、雨衣与帽子、右手握帽前景。右手前景来自同一穿戴母图，用于表现手指压住帽子的遮挡。卸衣时移除雨衣和握帽前景，恢复底图空手姿态。左手沿用完整底图。所有图层均为1024×1536，以画布原坐标叠加；不裁切透明留白，不分别调整宽高。

`split.py` 保存固定坐标蒙版及复现过程。普通运行只生成本目录的候选图；加 `--install` 才验证压缩并导出运行资源。`coat-mask.png` 和 `grip-mask.png` 分别记录雨衣与握帽区域。

原始生成图片带半透明氛围边缘。制作阶段将 alpha 小于128的像素置透明，其余置不透明，并清除透明像素隐藏颜色。这是有意的素材编辑，不属于无损压缩。底图和衣服的原始母图保留在各自来源目录。

## 无损压缩

在素材编辑完成后，使用 Pillow 12.3.0，PNG `optimize=True, compress_level=9`。逐一验证运行文件与压缩前候选图的尺寸、RGBA字节一致。只采用更小的结果，完整数据见 `compression.json`。

- 人物：680559 → 640500 字节。
- 雨衣：418654 → 385119 字节。
- 握帽前景：26380 → 25202 字节。
