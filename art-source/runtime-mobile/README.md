# 手机运行资源压缩

2026-10-16，用户明确允许运行图有少量颜色变化，并优先考虑手机加载速度。本次使用 Google libwebp（cwebp），不新增项目依赖。

命令：`cwebp -q 82 -m 6 -alpha_q 100 -sharp_yuv -mt SOURCE -o RUNTIME`。RGB 使用有损压缩；Alpha 保持无损。全部24张图的尺寸、比例与逐像素透明通道均通过 Pillow 比较。黑、白背景合成后的 RGB 平均绝对差最大为3.271/255；这不代替实际运行画面检查。

24张实际引用资源共35,735,607字节，压缩后6,473,018字节，减少81.9%。最大单图574,648字节。范围覆盖大厅、战斗角色与怪物图集、Boss、战区背景、地图、纸娃娃、装备和界面。逐项体积、尺寸、透明校验及母图位置见 `compression.json`。优先复用既有母图；只有没有原稿的文件才备份到 `originals/`。

运行图采用 `-mobile.webp` 文件名，避免手机继续命中旧大图缓存。Vite只发布代码和副本配置实际引用的图片；母图、历史候选与README不再进入Pages。下载并发限制为4，已成功资源在重试时复用。

此前全局无损要求在本次运行图压缩中由用户后续明确授权覆盖；母图仍保留原始像素。不得将本次RGB处理描述为无损压缩。
