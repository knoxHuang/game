# 装备、材料、掉落与三套神器

## 现行实现：三个槽与确定强化（2026-10-16）

新规则提供武器、护具、饰物三个槽。使用已有游戏图标和角色层，不引入随机词条或强化失败。新档有制式枪机和缝补雨衣；撑过第一波获得尚未拥有的袖珍罗盘，结算入库。背包中的装备可返所切换，局内不能换装。

| 基础装备 | 效果 | 强化装备 | 效果 |
| --- | --- | --- | --- |
| 制式枪机 | 伤害 +5% | 精校枪机 | 伤害 +10% |
| 缝补雨衣 | 最大生命 +10 | 潜水护衣 | 最大生命 +20 |
| 袖珍罗盘 | 收集半径 +0.5 | 风暴罗盘 | 伤害 +5%，收集半径 +0.8 |

每件强化消耗35冥币、25研究能量、2铜合金零件，确定获得强化版本并装备。保留基础版本；已拥有强化版不能重复扣费。普通材料约每五次击杀掉落一件，案件证据需要时仍伴随掉落。已拾取材料失败仍保留，案件证据不按材料保留。

训练与装备的永久伤害加成合计上限35%，最大生命加成上限40。局内辅助另计。下方九模板、随机装备与神器方案未在本次实现，不作为当前掉落承诺。

| 类别 | 首版数量与用途 | 放置位置 |
| --- | --- | --- |
| 武器 | 地区一 5 个模板：通用稳握/贯穿枪、三个职业保底武器；二区、三区各有对应进阶版 | 武器一槽；切职业换回已拥有的保底枪 |

| 案件证物 | 九项地区目标，任务专用；同一击杀可同时产生材料与装备 | 案件档案，背包无上限 |

## 2. 三地区装备模板

所有攻击伤害乘职业文档的等级倍率一次。射程单位与战区坐标相同。弱点倍率只在Boss的弱点开放时使用。

| 地区 | 武器：名称 / 职业 / 伤害 / 间隔 / 射程 / 特性 | 护具：普通 / 强化生命 | 饰物：移动 / 技能冷却 |
| --- | --- | --- | --- |
| 雾港沉船区 | 稳握手枪 / 通用 / 10 / 0.42秒 / 7.5 / 单体；贯穿手枪 / 通用 / 10 / 0.60秒 / 7.0 / 最多穿2只；黄铜左轮 / 枪手 / 10 / 0.38秒 / 7.5 / 单体；仪式符具 / 秘仪师 / 13 / 0.72秒 / 6.8 / 半径0.48；猎潮鱼叉 / 鱼叉 / 21 / 1.02秒 / 9 / 弱点2.6 | 防水外衣 +8 / 加固雨衣 +16 | 罗盘 +6% / 秘仪怀表技能冷却 −6% |
| 沉没修道院 | 校准左轮 18/0.38/7.5；蚀刻符具 23/0.72/6.8；钟索鱼叉 38/1.02/9，职业与特性同上 | 钟壳衬衣 +24 / 礼仪甲衣 +36 | 回声罗盘 +9% / 回声怀表技能冷却 −8% |
| 星蚀裂隙 | 星轨左轮 28/0.38/7.5；折光符具 36/0.72/6.8；执星鱼叉 59/1.02/9，职业与特性同上 | 星尘外衣 +44 / 裂隙甲衣 +60 | 星蚀罗盘 +12% / 裂隙怀表技能冷却 −10% |

基础枪开局穿戴，地区模板在各自Boss、副本怪与案件池中出现。职业基础枪由10级选职首次免费解锁，每职业只一把，不可出售或回收。切换职业移除不兼容枪到背包，并自动装备已有本职基础枪；没有就领取首次那把。职业枪可再从对应地区掉落同模版物品，重复品可回收。

鱼叉基础弱点倍率 2.6；其他枪1.8，秘仪符弹1.6。贯穿依命中顺序最多打不同普通怪两只，不穿墙，不在Boss多个部件上重复计数。地形和敌人不保证排成一线，因此穿透的理论上限不是保证收益。

移动速度词条叠加上限 +20%。技能冷却词条最多−10%（取可穿戴饰物的最大值，不相加）。它们分别只影响移动与主动能力，不改变自动射击节奏。护具只加生命，不作隐藏减伤。

## 3. 两层独立掉落

先判本次是否出现某类别，再从符合条件的物品池抽一次。技能饰物只有达到10级后才进入池；职业枪只在当前职业对应池出现。数值不因角色等级浮动。

| 来源 | 类别判定 | 物品池 |
| --- | --- | --- |
| 每只普通怪击杀 | 独立 2% 装备；独立 0.2% 神器部件 | 装备按地区与职业可用模板权重；部件选该地区未组装神器缺件，否则可重复部件 |
| Boss 击杀 | 固定一件地区装备；额外 20% 自然部件 | 符合当前职业的地区装备；Boss部件从本区神器三个缺件中等权选 |
| 首次职业解锁 | 不随机 | 给本职业基础枪一次 |
| 案件目标击杀 | 目标物固定掉落 | 按案件实例绑定；已完成/未接案件不重复产生专用证物 |
| 补给箱 | 配置固定材料量 | 位置和数量由副本配置决定，不抽装备池 |

普通装备池权重按“无职业 / 已转职”列出，合计均为100%。没有职业能力时技能饰物不入池，并把15%权重加给基础护具。

| 模板 | 无职业 | 已转职 |
| --- | ---: | ---: |
| 贯穿手枪 | 20% | 20% |
| 普通护具 | 35% | 25% |
| 强化护具 | 20% | 20% |
| 地区速度饰物 | 25% | 20% |
| 地区技能饰物 | — | 15% |

未转职地图池不会掉不可用职业枪。高级地区池先排除已有模板，再按上表权重重归一；池为空时改抽护具/饰物，不能生成空结果。不能把三地区所有 27 个模板同时扔入同一个池。

首区全杀112只的期望是 2.24 件普通怪自然装备，加 Boss 固定一件，约3.24件；自然部件期望为112×0.2%+Boss20%=0.424件。本期望不含保障，不代表每局固定掉这么多。三地区自然概率相同，怪更耐打不提高单杀掉落率。

## 4. 新手保障、案件证物与死亡

首局第2波第一件**已带回入库**的自然装备若未提供护具，则补一件防水外衣；失败没带回，下次重试仍可能保障。该保障使用独立来源标记，不影响Boss固定装备和常规自然掉落。第二件可用通用装备保障优先补未体验的贯穿手枪；若自然枪已入库则跳过，不发同枪副本。

首个无线电从首只有效目标潮蛰兽固定掉落，不看随机概率。其他任务证物只在接取对应案件时掉，拾取自动记入本次档案。击杀能量、装备、材料和证物互相独立，案件不会占掉装备或部件判定。

每次拾取加入本局临时清单，地面掉落和清单有稳定ID。Boss胜利后所有现存战利品汇集到已完成报告；自动安全返所并一次性入库。提前撤离只带实际拾取品；失败清空临时物品和本次未带回任务进度。已吸收能量不回退，已在仓库或已穿戴物品保留。

## 5. 回收、神器与阶段收益

重复普通/精良/稀有装备分别回收为 5 冥币+1零件、10冥币+1样本+1零件、20冥币+2样本+2零件。职业保底枪、当前穿戴、任务物、神器部件不允许回收。材料不回收神器本身。没有负重和容量，也不会自动替换穿戴。

| 地区神器 | 三部件 | 效果 |
| --- | --- | --- |
| 守夜灯芯 | 灯芯、铜框、封印纹章 | 职业能力有效命中后，给下一次自动射击充能；首次命中附加 8 点基础伤害、半径0.6；独立10秒冷却 |
| 沉钟圣匣 | 钟舌、回声罩、锁潮纹章 | 职业能力命中后，获得最大生命6%护盾3秒；独立12秒冷却，不回血、不叠加 |
| 裂星罗盘 | 棱镜、星盘针、空隙封印 | Boss弱点开放时下一次弱点命中额外+20%基础伤害；独立12秒冷却，普通怪不触发 |

每套适配任何职业。单次技能只能充一次神器；秘仪命中多人不叠层；神器伤害不能再次充能；贯穿枪第一目标命中触发一次。弹药击空仍消费“下一发”充能；命中Boss附加与神器伤害各结算一次。

三套都按各自Boss的第1/3/5次成功带回触发缺件保障；每次发该套未拥有的一个部件，优先固定顺序。自然掉落先入库，再发保障；自然掉落不取代一次尚未结算的保障。齐件或已解锁后停止发缺件保障，改普通Boss装备。反复导入、切角色、组装、拆装备不清除入库/胜利标记。每区完整至少五次成功带回可组齐三部件；自然掉落可能提前。组装成功为该账户一次永久解锁，消耗三个素材部件。

## 6. 平衡基线与实现边界

小怪首区10生命下，伤害8、射速0.46的贯穿枪需两发打两只，期望约2.17只/秒，弱于基础枪约2.38只/秒。因此采用10伤害、0.60秒：单体约1.67只/秒，敌人排齐的理想情况约3.33只/秒。该静态断点分析不能证明玩家会排齐。
