# 战斗与触屏操作设计

版本：1.1 制作说明。状态：策划定案，待用户审计。本文只定义设计，不包含游戏实现。

成长数值、生命、伤害和基础动作时长以[主设计第 5 与第 7 节](game-design.md)为准。本文定义触屏、判定、状态与攻击形状；同一规则只在所属文档维护。

## 1 世界单位与身体判定

一格等于一块地面格子的边长。身体判定使用脚底中心的圆形，不包含头部、武器和装饰。画面大小与身体判定分别定义。

| 对象 | 身体半径 | 移动阻挡 |
| --- | --- | --- |
| 玩家 | 0.22 格 | 墙体、障碍、关闭的门、敌人身体 |
| 普通近战敌人 | 0.30 格 | 墙体、障碍、门、玩家与其他敌人 |
| 普通远程敌人 | 0.28 格 | 同上 |
| 守卫 | 0.70 格 | 同上；守卫中心不得进入距墙体不足 1.5 格的位置 |
| 弹丸 | 0.15 格 | 碰墙或命中玩家后消失；不穿越房间 |

闪避期间玩家可穿过普通敌人的身体，仍受墙体、障碍、门与守卫阻挡。结束时若与普通敌人重叠，双方向最近的空地分离，不造成接触伤害。

伤害判定使用玩家与敌人的身体圆。攻击扇形与身体圆相交即属于命中范围。伤害数字和特效不改变判定。

普通攻击和冲击波命中还要求玩家脚底中心至目标脚底中心没有墙体或阻挡障碍。扇形特效不穿墙，不对隔墙目标造成伤害。落石、地刺和地面爆发按各自的地面区域判定，不使用玩家攻击的直线规则。

## 2 两指触屏规则

### 2.1 手指归属

- 左侧摇杆区按下的第一根手指负责移动，持续归属于摇杆，直到抬手或取消。
- 右侧按钮区按下的第一根手指负责动作，持续归属于右侧操作区。额外手指不产生额外攻击。
- 左侧手指划入右侧不会触发动作，越出摇杆区时停止移动，回到摇杆区后可恢复；其归属仍保留到抬手。右侧手指划入左侧不会移动角色。
- 信息面板打开、切后台、旋转和触摸取消时，清除两根手指的归属与持续输入。
- 在空白场景按下不触发攻击，也不接管摇杆。

### 2.2 右拇指切换

采用按钮间滑动切换。每个按钮使用自己的可见圆形作为触摸区，间隔为中性区。

| 手势 | 结果 |
| --- | --- |
| 在攻击按钮按下 | 立即开始一次攻击；保持按住时按节奏追加 |
| 从攻击滑入闪避 | 停止追加攻击，立即尝试闪避一次 |
| 从攻击滑入技能 | 停止追加攻击，立即尝试技能一次 |
| 从闪避或技能滑回攻击 | 当前不可打断动作结束后开始持续攻击 |
| 滑入中性区或离开右侧操作区 | 停止持续攻击，不触发其他动作 |
| 在冷却按钮按下或滑入 | 显示不可用反馈，不缓存指令 |
| 一直停留在闪避或技能按钮 | 只触发一次，不自动重放 |
| 抬手或系统取消 | 停止持续操作，未发生的追加攻击取消 |

手指必须离开动作按钮后再次进入，才能重新触发该动作。一次抖动重复触发不被接受；重新进入的间隔至少 0.08 秒。交互按钮只接受独立按下与抬起，滑过不执行，避免误开宝箱或撤离。

右手滑向闪避后不自动恢复攻击。玩家滑回攻击按钮或再次按住，才恢复追加。两指验收使用“左手持续移动、右手攻击滑向闪避再滑回”的具体手势。

## 3 玩家动作状态

```text
待机或移动 → 攻击准备 → 攻击命中 → 攻击恢复 → 待机或移动
     ↓            ↓          ↓          ↓
   闪避 ←──────── 任一可取消攻击阶段 ──────┘
     ↓
待机或移动

可受伤状态 → 受击 → 待机或移动
生命归零 → 倒地 → 失败结算
```

普通攻击准备、命中、恢复合计 0.55 秒。每次攻击的方向在动作开始锁定，判定以命中阶段内玩家的实时位置为中心。每个目标每次最多受伤一次，避免扇形持续重叠多次扣血。

冲击波为准备 0.15、命中 0.10、恢复 0.30 秒。命中扇形内每个敌人最多受伤一次。普通攻击与技能不并行。技能可以在待机、移动或普通攻击恢复阶段开始，并取消剩余恢复；普通攻击准备、命中、受击或闪避阶段不能发动技能，显示动作忙碌反馈，不缓存请求。技能动作结束后，仍在攻击按钮内按住的手指可以恢复攻击。

移动在攻击和技能中降为 50%，闪避过程中由闪避动作控制移动。玩家受击持续 0.12 秒，向伤害来源的反方向击退最多 0.4 格，受阻时缩短距离。

玩家受击打断未完成攻击或技能。已经发生的伤害不撤回；已开始的技能冷却保留。受击期间不能开始新攻击，允许输入闪避打断剩余受击动作，但不能取消已经扣除的生命。

## 4 打断与方向辅助

### 4.1 受击和击退

| 目标与情况 | 普通攻击 | 冲击波 |
| --- | --- | --- |
| 普通敌人待机、移动或恢复 | 显示受击闪光，击退 0.3 格；不重置原状态计时 | 击退 0.8 格，停止行动 0.25 秒 |
| 普通敌人攻击准备 | 仅显示受击闪光，保留准备计时；不击退、不打断 | 取消准备，击退 0.8 格，停止行动 0.25 秒，随后进入 1 秒恢复 |
| 普通敌人已经开始攻击 | 不取消已开始的攻击，不击退 | 不取消已开始的攻击，不击退 |
| 守卫任一存活状态 | 只扣生命并显示受击反馈，不击退、不打断 | 同左 |

受击闪光持续 0.08 秒，不暂停世界计时。普通攻击不能无限重置敌人预警。敌人生命归零立即停止未来攻击；已经发生的伤害保留。

### 4.2 辅助选取

辅助选取扇形为前方 120 度。目标中心距离必须不超过“1.2 格攻击距离＋目标身体半径”，并且玩家与目标间没有墙体或障碍遮挡。

每次攻击开始时选取最近可命中目标并锁定方向，没有目标则沿移动方向或最近移动方向攻击。不会自动追赶或转身攻击背后敌人。冲击波使用同样扇形规则，距离上限改为“2 格＋目标身体半径”。

可攻击目标脚下显示细圈。最近敌人距离不足时不显示选中圈，按钮仍允许挥空。方向辅助不保证目标在命中时仍然留在范围内。

## 5 普通敌人的行为流程

```text
巡逻 → 看见玩家 → 接近或保持距离 → 准备 → 攻击 → 恢复
          ↑                                      ↓
          └──────────────────────────────────────┘
任一状态 → 生命归零 → 死亡与掉落
```

- 发现条件：同房间内、距离不超过 6 格，且直线没有墙体或障碍遮挡。
- 巡逻：在生成点左右各一格的两个点间移动，阻挡时等待并折返。
- 追击：近战接近至 1.2 格；远程保持约 3 格，玩家靠近至 2 格时后退。障碍通过可行走空间绕行。
- 连续 2 秒看不见玩家时，停止发起新攻击并回生成点；回程受到攻击会再次发现玩家。
- 玩家离开房间时敌人不追出，未清理房间保留剩余生命，存活敌人回生成点。弹丸和进行中的危险标记清除。
- 近战只在一只敌人取得攻击机会后准备，其余继续走位。进入准备时锁定方向；攻击开始后不追踪转向。
- 远程只在玩家可见且位于 5 格内准备射击，准备结束时按已锁定方向发射。

| 敌人 | 攻击形状与时长 | 可见预警 |
| --- | --- | --- |
| 矿洞兽 | 直线扑击 1.5 格、持续 0.30 秒；扫过的身体圆命中玩家一次 | 身体压低，地面箭头标明路线，准备 0.7 秒 |
| 岩壳虫 | 单枚直径 0.3 格弹丸，速度每秒 3 格，存活最多 2 秒 | 外壳张开，发射方向细线，准备 0.9 秒 |
| 执念体 | 正前方 90 度、1.3 格扇形挥击，危险阶段 0.15 秒 | 举爪与扇形轮廓，准备 0.7 秒 |
| 骨灯使 | 中心方向及左右 25 度共三枚弹丸；速度、直径和寿命同岩壳虫 | 三条短射线与灯光蓄亮，准备 1 秒 |
| 黑曜兵 | 直线突刺 2 格、持续 0.35 秒；身体扫掠宽度 0.6 格 | 刀尖向后收，地面长箭头，准备 0.8 秒 |
| 魂火使 | 向准备开始时的玩家位置发射单枚弹丸，速度每秒 2 格，直径 0.3 格，寿命 3 秒 | 手中火球增大与落点方向提示，准备 1 秒 |

所有普通攻击结束后进入主文档规定的 1 秒恢复。弹丸不能穿过障碍。玩家受击保护期间其他命中不再扣血。

## 6 守卫的完整攻击方案

守卫发现玩家后按表中顺序交替攻击，攻击间按主文档规定恢复。准备开始时锁定位置或方向。召唤普通敌人、额外阶段与随机技能不在首版范围。

| 守卫与动作 | 预警 | 危险形状与持续 | 路线与安全空间 |
| --- | --- | --- | --- |
| 洞口守卫 冲撞 | 1 秒，宽 1.4 格箭头 | 直线最多 4 格，每秒 6 格；扫掠宽度 1.4 格，碰障碍结束 | 锁定玩家当时方向，两侧各留至少 1.5 格空间 |
| 洞口守卫 落石 | 1.2 秒，三个圆形标记 | 半径 0.6 格，落下时危险 0.15 秒，每个圆最多伤害一次 | 标记在玩家原位置及其左右各 2 格；标记间有空隙 |
| 封印守卫 横扫 | 1 秒，扇形填充与举臂 | 正前方 120 度、2.5 格，危险 0.20 秒 | 可退后或绕向背面，不临时转向 |
| 封印守卫 封印标记 | 1.2 秒，三个符文圆 | 半径 0.65 格，危险 0.20 秒 | 位置为玩家原位置和其左右各 3 格，可走出圆外 |
| 核心守卫 冲撞 | 1 秒，紫色箭头与下蹲 | 几何与速度同洞口守卫 | 保留两侧通路，生命半数以下只缩短恢复间隔 |
| 核心守卫 地面爆发 | 1.2 秒，中心圆与扩散轮廓 | 守卫原位置半径 2 格的圆，危险 0.25 秒 | 预警期间可退到圆外，范围不继续扩张 |

标记位置位于边界外时向房间内平移，确保标记不覆盖所有可行走空间；无法放置的侧标记取消，不叠在中心增加伤害。守卫冲撞路径遇障碍立即结束，仍进入完整恢复。

守卫攻击伤害以主文档为准。每项攻击每次对玩家最多伤害一次。多块落石重叠也不得在一次落石动作内重复扣血。

## 7 机关与交互判定

- 机关使用固定格子，预警 1 秒后产生伤害，间隔 2 秒再循环。
- 落石危险圆半径 0.5 格，危险持续 0.15 秒；地刺使用一格正方形，危险持续 0.5 秒。
- 机关各自命中一次后等待下一次循环。伤害与免伤规则以主文档为准。
- 宝箱、任务物品和装置在 0.8 格内可交互。多个目标按距离、任务目标优先、固定编号依次选取。
- 交互目标的图标、名称与场景描边必须一致。超过范围或被障碍阻隔后取消提示。
- 调查保持在 0.8 格内，按住交互 2 秒。移动离开、受击、松开或暂停会清空本次调查计时。

## 8 同时发生的事件

同一时刻先处理有效输入和动作切换，再确定命中，统一应用伤害，最后处理死亡与掉落。

有效闪避已在命中时刻开始且仍在免伤窗口，玩家不受伤。双方攻击在同一时刻已经命中时，双方都计算伤害；敌人死亡不会撤回该次已发生伤害。

玩家和守卫同时死亡时按冒险失败处理，不保留本次关键委托进度。玩家受击来源同时多项命中时，只计算伤害最高的一项；相同伤害按固定编号选择，随后进入受击保护。

暂停期间世界计时、冷却、机关、敌人、弹丸与调查全部停止。恢复清除输入，不自动追加动作。

## 9 验证清单

1. 左拇指不离开摇杆，右拇指可以攻击、滑向闪避、滑回攻击。
2. 普通连续攻击不会重置敌人预警；冲击波只能按规定打断普通敌人。
3. 辅助目标在有效范围内，隔墙敌人不会被选中。
4. 每种攻击的预警区域与实际判定一致；守卫始终保留躲避空间。
5. 同次挥击、落石、弹丸与机关不重复计算伤害。
6. 背包、地图、横屏和切后台中断后，恢复不会沿旧输入继续操作。
7. 所有触屏与战斗数值仍需原型验证；本说明没有宣称手感测试通过。
