# 手机竖屏界面设计

版本：1.1 制作说明。状态：策划定案，待用户审计。以下线框图和布局规格用于制作界面，当前没有运行页面或正式美术图。

玩法、费用与状态见[主设计](game-design.md)，触摸归属见[战斗设计](combat-design.md)，人物与图标见[角色设定](character-design.md)。

## 1 通用布局与视觉

可用区域指浏览器实际视口扣除设备安全区后的矩形。支持最小 320 × 480，参考 360 × 640。布局使用可用宽高 W、H，不依赖浏览器工具栏的固定高度。

功能面板使用顶部 52、底部 64 CSS 像素，中间内容区高度 H−116。正文在内容区滚动，标题、关闭和主要按钮保持可见。默认左右边距 16，卡片间距 12，主要按钮高度 48；最低正文 14，普通正文 16，标题 22。

最小视口下保持字号与按钮尺寸，缩短同屏内容并滚动；不把整个 UI 等比缩小。较高屏幕增加内容区高度。宽屏桌面居中显示不超过 480 像素宽的竖屏区域。

| 元素 | 视觉定案 |
| --- | --- |
| 页面背景 | 深蓝灰 `#17232C`，店铺场景使用暖色照明 |
| 卡片与面板 | 灰蓝 `#25323E`，细边框，圆角 8 像素 |
| 正文 | 米白 `#F3EAD9`，辅助文字 `#B7C0C7` |
| 主要按钮与任务标记 | 暖金 `#D8B66A`，搭配深色文字 |
| 角色与恢复提示 | 蓝绿 `#54C7BC` |
| 错误与危险 | 橙红 `#D16B62`，配文字与图形，不只改变颜色 |

按钮按下有轻微位移与描边反馈。禁用按钮保留文字和原因，降低亮度，不仅使用颜色区分。图标统一采用角色设定中的形状。

## 2 主界面

```text
┌──────────────────────┐
│                      │
│     深渊事务所         │
│   店铺门头与提灯背景    │
│                      │
│     [继续冒险]         │
│   二级店铺 · 第二层    │
│     [新游戏]           │
│     [设置]             │
│                      │
└──────────────────────┘
```

标题位于上方约 18% 高度，背景门头占上半部。菜单从约 48% 高度开始，按钮宽度 W−64、高度 48、间距 12。短屏时标题区缩至 120 像素，菜单区域可滚动。

无存档时“开始游戏”为首要按钮，隐藏继续。局内存档时继续按钮下显示“第一层冒险中”。新游戏覆盖已有存档先确认，取消保持原页面。读取失败覆盖为错误面板，提供重试、导出原数据和确认重置，不自动新建。

## 3 店铺主场景

```text
┌──────────────────────┐
│ 店铺二级   冥币 240   │
├──────────────────────┤
│       深渊出发门       │
│                      │
│      岚舟             │
│  阿砾          闻灯    │
│        玩家           │
│ 工作台        升级设施 │
├──────────────────────┤
│ 委托     仓库    设置  │
└──────────────────────┘
```

顶部 52 像素显示店铺等级、冥币。底部 64 像素提供委托、仓库、设置三个等宽入口。中部为店铺场景。

出发门位于场景 (50%,22%)，NPC 站位使用角色设定；玩家站在 (55%,70%)，工作台 (22%,78%)，升级设施 (80%,78%)。设施点击区至少 48 × 48，点击区之间不重叠。

点击 NPC 打开他的委托面板，工作台打开角色整备，升级设施打开店铺升级，门打开出发整备。店铺以点击入口操作，不要求先控制角色走到目标前。角色可播放走向设施的装饰动画，但不延迟打开面板。

一级场景显示阿砾，二级加入岚舟与地图筒，三级加入闻灯与灯架。新增 NPC 有一次淡入与简短到访提示。可交付标记优先于新任务标记。空任务位置不影响其他设施。

## 4 委托面板

```text
┌──────────────────────┐
│ 委托             [×] │
│ 阿砾 │ 岚舟 │ 闻灯    │
├──────────────────────┤
│ 已接 1/2              │
│ [矿灯图] 遗落的矿灯    │
│ 第一层 · 进行中        │
│                      │
│ [敌人图] 清出通道      │
│ 第一层 · 奖励 60 冥币  │
│ [接取后查看目标进度]    │
├──────────────────────┤
│ 选择任务后查看与接取    │
└──────────────────────┘
```

顶部标题区之后有 44 像素 NPC 标签栏。内容卡片最小高 96，按已接、关键、普通顺序排列。卡片显示目标图、名称、层数、进度和确定奖励。

点击卡片进入任务详情，展示目标图示、操作要求、风险与奖励。底部主要按钮根据状态显示“接取”“交付并领取”或“返回”；进行中任务提供次要的“放弃”按钮。放弃先确认，已保留进度与待领奖励明确列出。

未到访 NPC 标签显示身份剪影和店铺等级要求。深层未开放卡片显示层数锁定，不能接取。位置已满时显示“先交付或放弃当前任务”，不同层冲突时显示现有任务层数。

无任务显示 NPC 与一条说明。刷新只改变未接普通任务，当前选中卡片不突然消失。保存中禁止重复接取，保存失败保留卡片和重试操作。

## 5 出发整备

```text
┌──────────────────────┐
│ 出发准备         [×] │
├──────────────────────┤
│ [第一层] 第二层 第三层 │
│ 当前任务 2 项          │
│ 寻物图  清理图         │
│                      │
│ 角色  武器  护甲       │
│ 生命 120 · 伤害 15     │
│ 药品 1/2 [补充一瓶]    │
├──────────────────────┤
│       [进入深渊]       │
└──────────────────────┘
```

内容自上而下为层数卡片、已接任务、装备摘要和药品。层数卡片横向排列，每张至少 80 像素宽，窄屏可水平滚动。被锁定层显示解锁任务与条件。

出发自动选择当前任务层数；没有任务时主要按钮变为“去接取委托”。两项任务须同层。药品先显示免费数量，购买第二瓶在按钮上直接显示 10 冥币；费用不足给出差额。

点击进入先保存本次整备，再显示加载界面。资源加载失败提供重试或回店，未开始冒险时不消耗本次药品。成功后进入安全入口并显示继续按钮。

## 6 角色成长

```text
┌──────────────────────┐
│ 角色整备         [×] │
├──────────────────────┤
│     玩家全身预览       │
│ 生命 100 → 120         │
│ 短剑 │ 护甲 │ 能力    │
│ 当前档位与下一档预览    │
│ 效果变化               │
│ 冥币 40  铁片 2        │
│ 当前拥有与缺少数量      │
├──────────────────────┤
│       [确认强化]       │
└──────────────────────┘
```

角色预览占内容区前 120 像素，下面是 44 像素分类标签，之后显示选中项目。强化时不改变预览位置，采用左右切换查看当前和下一档。

等级不足显示“二级店铺开放”，材料不足显示具体差额。最高档显示“已完成强化”，隐藏购买操作。确认弹窗列出一次性费用与效果，保存成功后更新形象、数值和余额；失败保留原状态，弹出重试。

材料背包不设容量，角色面板没有背包扩容项。

## 7 店铺升级

```text
┌──────────────────────┐
│ 店铺升级         [×] │
├──────────────────────┤
│ 一级店铺 → 二级店铺    │
│ [当前图]  [升级后图]   │
│ 开放：二级装备、冲击波 │
│ 到访：勘探员岚舟       │
│ 下一层解锁委托         │
│ 费用与当前资源         │
├──────────────────────┤
│       [升级店铺]       │
└──────────────────────┘
```

图示各占半行宽，高约 100 像素。解锁内容使用图标列表，明确区分“开放获取途径”与“立即获得装备”，避免玩家误以为升级直接装备最高档。

资源不足时按钮禁用并列出差额。最高级展示已开放内容，无下一等级。升级确认后回店，外观变换、新 NPC 和新任务提示依次出现，不同时叠多个弹窗。

## 8 战斗界面与短屏适配

顶部信息区 52 像素，下方操作区 160 像素，场景高度 H−212。控制区使用低透明深底，敌人不得进入控制区对应的屏幕遮挡区域。

地图格显示边长取整数：不超过 min(W/12, 场景高度/12)，向下取整。在 360 × 640 下为 30 像素，在 320 × 480 下为 22 像素。场景至少可显示十二格纵向，主要十格战斗区可以完整显示。房间超过视野的部分通过镜头滚动探索。

| 控件 | 中心坐标或区域 | 大小 |
| --- | --- | --- |
| 移动摇杆区 | 左下，中心 (72,H−76) | 120 × 120 |
| 攻击 | (W−48,H−48) | 直径 72 |
| 闪避 | (W−124,H−48) | 直径 56 |
| 技能 | (W−48,H−124) | 直径 56 |
| 条件性交互 | (W−124,H−124) | 直径 48 |
| 生命 | 顶部左侧，宽约 45% | 高 20，带当前数值 |
| 任务入口 | 顶部中间 | 点击区至少 48 × 48 |
| 暂停 | 顶部右侧 | 点击区 48 × 48 |

技能未获得时保留该处空白，不显示不可用大按钮。交互仅在目标附近出现，名称显示在按钮上方。冷却填充与数字放在动作按钮内部。右侧最近两个圆的边缘间距至少 12 像素。

守卫生命条在场景顶部占 24 像素。出现守卫时，格子缩放按再扣这 24 像素计算；最小屏幕仍有至少十二格纵向视野。玩家通常位于场景高度 58% 处，边界时镜头停止滚动。

击败提示和任务进度只出现一条短提示，不覆盖预警。材料拾取在左侧显示图标与增加数量，不要求点击。失败后停住操作，播放倒地再进入结算。

## 9 暂停与地图

```text
┌──────────────────────┐
│ 已暂停            [×]│
├──────────────────────┤
│ [继续]               │
│ [地图] [背包] [任务]  │
│ [声音与表现设置]      │
│ [放弃本次冒险]        │
└──────────────────────┘
```

继续为最上方主要操作。放弃置于最下方次要危险操作，点击后列出本次会损失的材料与进度，确认才执行。

地图使用同一面板模板，内容为七房间节点图，可缩放到完整容纳。当前位置用蓝绿边框，已清理用勾，任务目标用金色菱形，入口用门图标。未探索节点隐藏内容，只显示已发现的相邻门。不能点击地图传送。

从暂停切到地图或其他子面板时保持暂停。返回回到暂停面板，只有点击继续恢复战斗。

## 10 背包与任务记录

```text
┌──────────────────────┐
│ 本次收获          [×]│
├──────────────────────┤
│ [碎晶] 数量 8         │
│ [铁片] 数量 7         │
│                      │
│ 任务物品与记录         │
│ [矿灯] 已取得待撤离    │
│ 药品 1/2 [使用]        │
├──────────────────────┤
│       [返回暂停]       │
└──────────────────────┘
```

材料使用按种类累计的列表，不显示空格、负重或容量数字。为空时显示“本次尚未收集材料”。不提供材料丢弃按钮。

任务记录单独列出目标、已安全保存的进度和本次新增进度。店铺仓库使用相同列表结构，标题改为“仓库”，不显示本次药品或待撤离进度。

满生命时恢复药按钮禁用并说明“生命已满”。药品为零时显示“已用完”。局内使用成功后回暂停面板；药品数量与生命一起保存。

## 11 成功与失败结算

```text
┌──────────────────────┐
│       成功撤离         │
├──────────────────────┤
│ [材料] 碎晶 +5 铁片 +4 │
│ 委托：1 项可交付       │
│ 清理记录：安全进度 4/6 │
│ 补给消耗、主要受伤来源 │
│ 冥币奖励：回店交付领取 │
├──────────────────────┤
│        [返回店铺]      │
└──────────────────────┘
```

失败沿用布局，标题为“冒险失败”，内容分为“本次损失”“保留成长”“可以重新出发”。不显示未获得的奖励为已得收入。

结算材料最多先显示六类，其余通过滚动。确认按钮固定底部。重复点击不重复入库。恢复未关闭的结算时展示同一结果。

## 12 交付与主线完成

交付使用委托详情结构：顶部 NPC 头像与名称，中部为目标勾选、凭证、确定奖励，底部“交付并领取”。全部达成任务在列表顶部提供“全部交付”，确认面板逐项列出奖励总和。

无可交付任务时显示当前目标，不使用空领取按钮。保存中显示“正在保存”，完成后显示一次奖励动画并清除可交付标记。

主线完成使用全屏结构：顶部“深渊核心已带回”，中部为三级店铺与三位 NPC 的场景、已开放层数和简短总结，底部“继续冒险”。没有额外长文本分支。

## 13 设置 加载 与通用状态

设置按音乐、音效、减少震动、帮助、存档管理排列，每项使用文字与开关或按钮。局内隐藏导入、导出和重置，防止替换进行中的冒险。

加载界面显示区域图标、资源进度和一句当前目标。失败显示失败内容、重试和回店；已开始的冒险恢复失败时不提供直接回店拿成果，提供返回主界面。

| 状态 | 统一行为 |
| --- | --- |
| 默认 | 一项主要动作，次要动作外观较轻 |
| 空内容 | 图标、说明及可前往的入口 |
| 锁定或资源不足 | 保留内容，显示条件，禁用对应购买或接取 |
| 确认 | 列出影响，提供确认和取消，取消不改状态 |
| 保存中 | 暂停相应操作，显示进度，禁止重复点击 |
| 保存失败 | 保留有效数据，显示重试；战斗保持暂停 |
| 内容过长 | 内容区滚动，标题与主要按钮固定 |
| 手机中断 | 恢复遮罩优先于所有操作，点击继续后清除旧输入 |

页面不使用浏览器系统弹窗作为主要流程。每个功能面板的关闭和返回都由游戏 UI 提供。

## 14 布局复核要求

必须检查无存档、有局内存档、零资源、满级店铺、两项任务、深层锁定、材料为空、恢复药耗尽、失败、保存错误与加载错误状态。

对 360 × 640 和 320 × 480 各检查一遍全部页面。数值可在文档阶段推算，实际文字溢出、触摸与浏览器安全区在制作后验证；本文不声称已经完成屏幕截图或真机验收。
