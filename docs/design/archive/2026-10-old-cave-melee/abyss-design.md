# 深渊路线与房间配置

版本：1.1 制作说明。状态：策划定案，待用户审计。本文给出三层、六套路线的完整配置，当前没有制作地图资源或运行关卡。

数值见[主设计](game-design.md)，攻击与判定见[战斗设计](combat-design.md)，场景与怪物外形见[角色设定](character-design.md)。

## 1 坐标 门 与房间规则

房间网格为 12 列 × 16 行。左上角为 (1,1)，横向向右增加、纵向向下增加。表中坐标代表格子中心。

四周边界为墙，内部 (2..11,2..15) 可以行走。障碍格整体阻挡，装置、宝箱与物品只占中心小范围；交互对象不能堵住唯一通路。

| 门方向 | 门格 | 入场位置 | 外观 |
| --- | --- | --- | --- |
| N 上 | (6,1) | (6,2) | 前往上方房间的门或通道 |
| S 下 | (6,16) | (6,15) | 返回下方房间的通道 |
| W 左 | (1,8) | (2,8) | 左侧通道 |
| E 右 | (12,8) | (11,8) | 右侧通道 |

路线表中的门才实际开放，其余边界保持墙体。关闭的前进门显示栅栏，进入当前房间的回程门保持开放。安全房的门无战斗锁。

首次进入敌人房提供 0.8 秒观察时间，本次冒险回访该房不重新提供观察保护。入场点被动态角色占用时，玩家放在相邻最近的空位置，不叠在敌人身上。

清理房间全部敌人后开启前进门。回访保留死亡敌人与已领取物品状态，不刷新奖励。守卫房是当前路线终点，守卫后方的深层门只作剧情反馈，真正进入下一层仍从店铺出发。

## 2 六套路线与门连接

所有路线使用 R0 至 R6 七个房间。房间身份固定，连接和实际场景配置由本节与后续表共同确定。

| 房间 | 功能 |
| --- | --- |
| R0 | 安全入口与撤离装置 |
| R1 | 基础战斗房 |
| R2 | 安全岔路与少量补充材料 |
| R3 | 委托目标房 |
| R4 | 关键委托守卫房 |
| R5 | 可选支路战斗房 |
| R6 | 可选材料房 |

```text
A 路线：R0 ─ R1 ─ R2 ─ R3 ─ R4
                   │
                   R5 ─ R6

B 路线：R0 ─ R1 ─ R2 ─ R3 ─ R4
             │
             R5 ─ R6
```

| 路线 | 主路线门连接 | 支路线门连接 | 场景配置 |
| --- | --- | --- | --- |
| 第一层 A | R0.N↔R1.S；R1.N↔R2.S；R2.N↔R3.S；R3.N↔R4.S | R2.E↔R5.W；R5.N↔R6.S | 第一层覆盖表与 A 位置 |
| 第一层 B | R0.N↔R1.S；R1.E↔R2.W；R2.N↔R3.S；R3.E↔R4.W | R1.W↔R5.E；R5.N↔R6.S | 第一层覆盖表与 B 位置 |
| 第二层 A | R0.N↔R1.S；R1.N↔R2.S；R2.N↔R3.S；R3.N↔R4.S | R2.E↔R5.W；R5.N↔R6.S | 第二层覆盖表与 A 位置 |
| 第二层 B | R0.N↔R1.S；R1.E↔R2.W；R2.N↔R3.S；R3.E↔R4.W | R1.W↔R5.E；R5.N↔R6.S | 第二层覆盖表与 B 位置 |
| 第三层 A | R0.N↔R1.S；R1.N↔R2.S；R2.N↔R3.S；R3.N↔R4.S | R2.E↔R5.W；R5.N↔R6.S | 第三层覆盖表与 A 位置 |
| 第三层 B | R0.N↔R1.S；R1.E↔R2.W；R2.N↔R3.S；R3.E↔R4.W | R1.W↔R5.E；R5.N↔R6.S | 第三层覆盖表与 B 位置 |

B 位置对后续配置中的障碍、敌人、机关、目标与宝箱统一使用横向镜像：横坐标 x 改为 13−x，纵坐标不变。门与入场位置以路线表为准，不进行额外镜像。该规则完整定义 B 路线，不要求制作者自行选择对象位置。

六套路线在敌人、机关和障碍上使用各层覆盖，不仅替换背景名称。首次新手固定第一层 A，后续从已选层的 A、B 等概率选择。

## 3 七个房间的基础配置

M 代表本层近战敌人，R 代表本层远程敌人，G 代表本层守卫。障碍坐标每个都占一格。

| 房间 | 基础障碍 | 敌人生成点 | 交互目标或宝箱 |
| --- | --- | --- | --- |
| R0 | 无 | 无 | 撤离装置 (6,5) |
| R1 | (5,8)、(6,8) | M：(4,5)、(8,5)；R：(6,3) | 无 |
| R2 | 无 | 无 | 材料箱 (8,6)，本层材料 A ×1 |
| R3 | (4,9)、(8,9) | M：(4,6)、(8,6)；R：(6,5) | 寻物点 (6,3)；调查点 (9,3)；材料箱 (3,4)，材料 B ×2 |
| R4 | 无 | G：(6,6) | 守卫死亡位置产生任务凭证与 A ×2、B ×2 |
| R5 | (5,9)、(6,9) | M：(4,7)、(8,7)；R：(6,4) | 无 |
| R6 | (4,8)、(9,8) | 无 | 材料箱 (4,4)，A ×1；材料箱 (8,4)，B ×2 |

基础障碍都是可绕行的小块。守卫房不设置阻挡障碍或独立机关，保证回旋空间。任务物品与调查装置不会占用同一位置。

宝箱需要主动打开，材料随后靠近自动拾取。每个箱子在本次冒险只发放一次。宝箱作为小物件不封住完整格子，其身体半径为 0.25 格。

## 6 任务配置合并与新手覆盖

每个房间的敌人配置与已接普通任务类型无关，保持基础数量。清理任务的六只 M 分别位于 R1、R3、R5，每房两只。远程敌人不计入该清理任务。

寻物任务在 R3 寻物点生成对应物品，调查任务在调查点生成对应装置；清理任务增加计数目标标记，不额外加敌人。接取两项任务时按目标类型合并，敌人和材料只生成一次。

没有寻物或调查任务时，对应点为空装饰，不生成可领取任务凭证。任务已经可交付时，其目标不再生成。守卫房只在对应关键委托仍进行中或当次已达成待撤离时开放，安全凭证已带回的关键任务不会重新打开守卫房。

| 任务组合 | R3 目标 | 其他变化 |
| --- | --- | --- |
| 寻物＋调查 | 两个独立目标同时出现 | 按坐标分别交互 |
| 寻物＋清理 | 寻物点出现物品 | M 六只显示任务标记 |
| 调查＋清理 | 调查点出现装置 | M 六只显示任务标记 |
| 关键守卫＋普通 | R4 开放，对应普通目标正常生成 | 两项任务独立计数和交付 |

新手 K0 覆盖：只接一项任务；第一层 A 的 R1 改为一只矿洞兽 (6,5)，R3 改为两只矿洞兽 (4,6)、(8,6)，不生成远程敌人。勘探仪放在寻物点，清理 R3 后才可拾取。R5 仍为普通支路配置，玩家可以首次看见岩壳虫。R4 关闭。

新手提示不改变判定或免费给予额外伤害保护。暂停提示关闭后从同一时刻继续。

## 7 精确掉落与预算

每只 M 掉材料 A ×1，每只 R 掉材料 B ×1。敌人与宝箱的独立编号用于防止再次领取。任务材料奖励在店铺交付时入仓库，不算作局内掉落。

| 区域 | A 数量 | B 数量 | 来源 |
| --- | --- | --- | --- |
| R1 | 2 | 1 | 两只 M、一只 R |
| R2 | 1 | 0 | 补充箱 |
| R3 | 2 | 3 | 两只 M、一只 R、B ×2 箱 |
| 主路线合计，不含守卫 | 5 | 4 | R1＋R2＋R3 |
| R5 | 2 | 1 | 支路三只敌人 |
| R6 | 1 | 2 | 两只材料箱 |
| 主路线与支路合计 | 8 | 7 | 主路线＋R5＋R6 |
| R4 守卫额外 | 2 | 2 | 击败守卫后随凭证出现 |
| 全路线含守卫合计 | 10 | 9 | 普通路线与守卫成果 |

新手主路线是 A ×4、B ×2；连同支路是 A ×7、B ×5。以上尚未加入主设计中的新手交付奖励。

材料全部可携带，没有背包取舍。支路提供额外材料，但多一次战斗与机关风险。玩家主要根据生命、药品和下一项成长需求决定是否继续。

## 8 回程 失败 与重入

任务房有通向来路的开放门，守卫房也允许退回。退出未清理房间时，敌人保留生命并回生成点；回访不重置材料、任务目标、机关领取或观察保护。

已清理战斗房回程无敌人。机关仍按暂停后的世界计时运行，玩家可以沿安全路径绕开。安全入口、岔路没有机关。

本次生命归零或主动放弃时，本次全部材料和新增任务进度丢失。重新出发是新冒险，重新配置路线、目标与敌人；仓库、安全任务进度和永久成长保留。

## 9 地图复核标准

1. 六套路线的七个房间均可以从入口到达，守卫门按关键委托状态控制。
2. 每个开启的门、目标和宝箱可通过静态障碍之间的路径接近。
3. 敌人、机关、任务目标和宝箱不会生成在障碍或边界墙中。
4. 清理目标有六只 M；新手覆盖和任务组合不重复生成敌人。
5. 普通主路线材料合计 5/4，含支路 8/7，含守卫 10/9，新手单独计算。
6. 每个危险房保留可绕行机关与撤退空间。守卫房没有额外机关和阻挡物。
7. 静态配置检查不替代实际移动、碰撞、镜头和战斗试玩。
