# 主角、NPC、眷属与Boss视觉方案

版本：4.0。日期：2026-10-15。状态：策划定案，待用户审计；规则与数值是完整设计，尚未实现或试玩。本轮仅更新文档。

本文件统一外形、角色识别、动作及原著/游戏原创边界。技能数值见[职业](career-design.md)，攻击规则见[战斗](combat-design.md)，资产技术规格见[副本生成流程](../agents/dungeon-generation.md)与[共用游戏美术](../../public/assets/game/README.md)。

## 1. 主角与六职业形态

主角林烬采用固定脸、发型和普通内搭，开局已穿黄色雨衣。整备立绘正面偏侧站立并露出脸。卸下护具后显示普通内搭；重新穿戴后恢复雨衣。人物底图、护具、武器与配件分层，不按装备组合生成整张人物。黄色雨衣、帽子、背包、靴子和外勤手枪保留为外勤识别元素。1～9级是见习外勤，没有职业徽记或超自然技能，但会使用移动、自动射击和闪避。10级转职保留同一脸/发型/身体辨认度，只替换外套领口、肩部器具、武器与弹道；手持武器不改变脚底锚点或碰撞轮廓。

| 职业 | 外观关键 | 攻击识别 |
| --- | --- | --- |
| 异闻枪手 | 黄色雨衣+黄铜左轮+照明镜 | 暖黄单弹、标记符号 |
| 秘仪师 | 雨衣内衬加入紫黑符袋/腕带，保留主角剪影 | 紫青符弹、小范围圆形印记 |
| 鱼叉猎手 | 肩背鱼叉枪、侧背缆绳 | 长青白鱼叉弹、命中弱点牵线 |
| 灯誓游侠/守望者 | 枪手基础上增加灯纹肩饰与逐级徽记 | 第三发标记命中有清晰铜金计数 |
| 猎魔枪匠/终焉枪匠 | 枪手加入弹道刻线与穿透枪口结构 | 多目标子弹保留相同色调、明确穿透链 |
| 秘仪/星蚀两支进阶 | 紫黑层次、肩部符匣与腕部光环不同 | 封印边界与星蚀阵轮廓不同 |
| 鱼叉两支进阶 | 缆绳扣/锚纹层级不同，不扩大玩家身形 | 单点弱点标记/有上限三目标链光 |

二转与高阶不生成新完整骨架，首版按现有服装/附件叠加，单人制作可控。敌我弹幕不可共用颜色和轮廓。减动效时职业仍可从武器、衣领和图标认出。

## 2. 三名NPC

| NPC | 外观与性格 | 在循环中的一次明确帮助 |
| --- | --- | --- |
| 港务联络员祝苇 | 防水制服、港区钥匙、登记册；务实，先问人是否回来 | 发K0、普通案件、领取一次性提交奖励 |
| 灯塔守夜人顾檀 | 长雨衣、旧提灯、耳机与折叠图；谨慎，不夸大神迹 | 指引信标，登记三次Boss报告和结尾 |
| 民俗学者闻宁 | 护目镜、录音机、注释仪式本；承认不确定性 | 解释三地仪式线索、神器缺件与地区报告 |

NPC不使用时间刷新。对话有可见表情/手势与背景道具变化；同一剧情不连续刷同一长文本，报告可回看，全部可跳过。

## 3. 九种普通异常生物

每地区提供近战、弹道远程、范围法术各一只。统一动作是 idle/chase/windup/attack/recover/hurt/defeat；不同在身体结构、攻击动作和地面危险图案，而非换颜色。

| 地区 | 近战 | 弹道远程 | 范围法术 |
| --- | --- | --- | --- |
| 沉船区 | 潮蛰兽：低伏、甲板短冲、触碰扑击 | 附蛰虫：背甲张开，发射可见针状弹 | 溺亡秘仪师：举符灯，圆形落点后爆发 |
| 修道院 | 钟壳守徒：钟壳前倾，短距离撞击 | 珊瑚射手：从腕珊瑚发射可见孢囊 | 祷潮者：双手抱钟，水面环纹标明脉冲 |
| 星蚀裂隙 | 虚潮鳗：身体蓄直线冲刺，轨迹提前出现 | 星隙观测者：停下对准，发射直线光矛 | 折星信徒：地面星形标记，短延迟落下星尘 |

Boss/眷属关系均是游戏改编，不声称与原著存在。自然drop只按战斗槽位分：近战主要铜件、远程样本、法术样本；案件证物只在对应案件承接时掉。表情不细腻时仍保留头/武器方向和预警动作。

## 4. 三个Boss视觉与动作

| Boss | 剪影和弱点识别 | 两阶段环境动作 |
| --- | --- | --- |
| 潮汐巨像 | 六触肢、肩部藤壶、胸侧发光腮 | 横扫触肢落地后腮部张开；二阶段海水反向涨落、落点增加 |
| 万眼主祭 | 礼冠状珊瑚、多个大小不同的眼、下垂披覆触腕 | 钟室回声显成扇形波纹；多眼睁开预告多点落区，恢复时主眼亮起 |
| 克苏鲁化身 | 巨型头部、触须下颚、翼状上肢、胸前星核 | 远景阴影占战区后缘；空间裂线预告扫击，星核开合标示窗口 |

“巨型”通过背景尺度、跨瓦片轮廓和与小队的比例表现，不遮满可移动区域。战斗碰撞轮廓与插画尺寸分别配置。攻击方向/弱点不仅变色，还需姿态、图标或轮廓提示。每只Boss的外观是游戏版设计；在原著来源核对并审核前，不能称为原著逐字造型。

## 5. 动画、特效与声音

普通怪每个动作至少能从低帧数看清；windup固定方向后保持可识别姿势。Boss攻击预警顺序：环境/地面固定形状→计时结束→攻击帧→恢复弱点。粒子不把安全区盖住，不震镜头强迫阅读。四向移动需支持斜向、停步和边缘行走；高阶服装使用部件叠层，不要求另做六套骨架动画。

| 声音 | 用途 |
| --- | --- |
| 海港 | 低雨、潮水、远处无线电；大厅音乐稀疏 |
| 预警 | 近战冲锋、弹道上膛、法术落点三种音色不同 |
| 自动射击 | 不同武器有发声/弹道反馈，不用UI按钮假装攻击 |
| Boss | 出场低频、每种招式单独提示、弱点开放短音 |
| 基地 | 提交纸张、金币/材料入库、NPC短确认 |

静音后危险仍由画面独立传达；Reduced Motion不通过关闭伤害动画隐去命中结果。视觉美术资产来源、每张图集和实际内容bounding boxes必须记录；不把这次文字设计称作资产已交付。

## 6. 视觉验收

1. 黄色雨衣角色在大厅和战斗都可认出；职业区别不需读长职业说明。
2. 每种小怪在48px视觉高度仍能区别攻击行为；Boss足够大，弱点不被HUD盖住。
3. 同时显示四方刷新预警时，生成箭头不混淆Boss攻击预警。
4. 减少动态、静音、320×480均能看明白移动/攻击/弱点。
5. 配置角色/怪物ID、图集帧区、来源记录对应到真实资产；字段校验与图片抽查都需执行。

当前共用像素原型已存在；其他两个地区完整独立造型、图集和效果尚未完成。

### 本轮整备立绘实现（2026-10-15）

整备页已使用人物底图与透明雨衣叠层，职业武器独立显示。穿戴状态保存在v3可选字段`armorEquipped`，缺字段旧档默认穿戴。卸下护具不丢加固进度，暂停加固生命加成；调查中禁止穿脱。大厅待机及战斗方向动画仍使用原图集，本轮没有把静态立绘冒充战斗换装。资源与提示词见[立绘来源](../../public/assets/character/README.md)。

## 7. 世界海图中的Boss污染（2026-10-15）

先确定地点放置的Boss，再核对原著或项目原创设定，最后确定污染方式与环境。不先画通用奇观，再往地图上放Boss。具体矩阵和原著链接见[当前海图来源](../../art-source/world-map/README.md)。潮汐巨像与万眼主祭仍属原创；克苏鲁化身的环境依据拉莱耶的巨石、黏液、门扉与异常几何，化身及其具体能力仍为游戏改编。未确定Boss的海域不提前指定独有污染。
