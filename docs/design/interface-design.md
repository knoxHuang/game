# 手机竖屏界面与操作流程

## 现行实现：手机资源体积与加载（2026-10-16）

用户后续明确允许少量颜色变化，并优先考虑手机加载速度。24张实际引用图像统一使用libwebp质量82的运行版，保留尺寸、比例与完整透明通道；涵盖战斗、Boss、背景、海图、人物和界面。RGB压缩为有损，母图单独保留。原稿映射及验证见 `art-source/runtime-mobile/`。

运行图总量从35.74 MB降为6.47 MB；发布仅包含实际引用资源。启动仍先加载13项共用与大厅图像，区域资源在出发时加载；下载并发限制为4。原无损运行路径及22.3%的记录为历史实现。

## 现行实现：启动资源进度（2026-10-16）

按用户要求，启动时先加载大厅、共用角色与怪物图集、物品和界面素材。进度条按实际完成数量显示比例，共13项；未全部成功时不开放首页或恢复调查。加载失败显示失败数量，重试只重新请求缺失资源，存档在资源就绪后读取。副本专属资源继续按需加载。

11张大图改用保持原尺寸和全部RGBA像素的无损WebP，共减少22.3%传输体积；来源与验证见 `art-source/startup-loading/README.md` 和 `art-source/lobby/loading-optimization/`。大厅保留局部图像加载状态和失败重试入口。

## 现行实现：统一像素海港与神秘刻线（2026-10-16）

依据用户后续反馈，当前界面采用大厅及共用旧木黄铜面板相同的精细像素画法。顶部、侧缘和底部在同一张透明母图中生成；不采用肉质侵蚀、怪脸或星空玻璃。罗盘、侧缘与底座通过残缺海图刻线、暗青反光和潮痕表达神秘影响。边框贴住屏幕，中央保持透明。

顶部与镜头安全区统一为80 CSS像素。生命数值叠加到真实生命条，经验为独立3像素细线；等级、波次、增援、残敌仍由真实状态显示。暂停保持48×48触摸范围。右侧底座放置急救与闪避，至少56×56；临时交互及旧规则职业能力保留在底座上方。无新增循环动画。Boss内衬复用同张母图的木材区域，保持28像素高度。

素材、完整提示词和无损验证见 `art-source/ui/harbor-mystery/README.md`；当前截图见 `artifacts/harbor-mystery/`，包含三个竖屏尺寸、112残敌、濒危、冷却与减少动态。未改用户存档，尚未真机测试。本节覆盖下方历史候选的造型、64像素高度及布局描述。

## 历史候选：统一海兽铜雕战斗边框（2026-10-16）

按用户本次美术描述，上下栏由同一张母图一起生成，使用海兽铜雕、锈蚀古金属、深海珊瑚、黑色黏液与静态绿符文边缘；深海色内衬承载生命和经验，羊皮纸条承载波次、增援与残敌。使用透明独立资产，数值与进度继续由真实游戏状态绘制。顶部仍占64 CSS像素，暂停保留48×48触摸范围。生命低于或等于30%仍显示“濒危”及暖色血条。按用户后续反馈，上边和左右两边贴边铺满，装饰在视口边缘裁切，文字保留内边距。此节覆盖下节渐隐底与9/3像素进度条的视觉描述；新生命槽7像素、经验线2像素。底部也贴边铺满，急救与闪避置于右侧双卡槽，按钮至少56×56像素；左侧底座仍支持起拖，临时交互与旧规则职业能力显示于底座上方。此布局覆盖下方旧浮动圆按钮位置。未增加循环动画。

内置ImageGen母图、提示词和无损压缩验证见 `art-source/ui/battle-frame/README.md`。隔离内存夹具的三个竖屏尺寸截图见 `artifacts/battle-status/`，未修改用户存档，尚未做手机真机验收。

独立视觉评审后的完善：长屏战区外的海面延伸到底座后方，消除纯色空带，竞技场比例与碰撞不变。Boss栏复用同套深海金属内衬和细黄铜边缘，仍高28像素。闪避冷却显示秒数并压暗槽内图标，去除额外矩形轮廓。三个竖屏尺寸的普通、濒危、Boss及冷却截图已通过独立复查。

## 现行实现：战斗顶部视觉层次（2026-10-16）

顶部继续保留64 CSS像素和原有镜头安全区域。撤去整块矩形金属框，使用深海色渐隐底。生命读数以21像素数字为主，下方为9像素生命槽及3像素蓝色经验线；等级放在生命读数右侧，波次、增援和残敌合并到一条次要信息行。经验的精确数值保留在进度条可访问文本和提示中。生命低于或等于30%时，使用静态暖色血条及“濒危”文字，不添加闪烁。

暂停使用30像素黄铜圆形图标，实际按钮保留完整48×48像素矩形触摸区域；键盘焦点有明确轮廓。Boss栏继续占28像素，显示14像素名称及第一阶段、第二阶段或弱点暴露，血条减少边框并统一材质色调。浮动摇杆、急救、闪避和补给规则保持现行实现。

## 现行实现：浮动摇杆与紧凑战斗HUD（2026-10-16）

战场空白区域支持按下起拖。摇杆以真实按下点为中心，仅在操作时显示。拖出外圈仍按方向移动，最大速度封顶；松手、触控取消、捕获丢失、失焦、窗口尺寸改变或暂停时清除输入。屏幕边缘不强行挪动计算中心，避免按下即移动。暂停、面板和操作按钮保留各自的触摸入口。

移动和动作分别认领触点。第二根手指可操作闪避、急救或交互。释放动作触点不终止移动；释放移动触点不打断另一个触点的持续交互。自动射击与键盘操作继续保留。帮助页说明浮动摇杆操作。

战斗顶部固定64 CSS像素，显示生命、局内等级/经验、波次/增援和残敌。暂停按钮为48×54像素。闪避上方提供56×56像素急救按钮，间隔16像素，始终显示剩余数量。战斗急救立即恢复40生命并自动保存，不暂停、不清除移动输入；满血或耗尽时禁用。急救需在按钮内松手确认，从其他动作滑过、取消触控或在按钮外松手均不消耗。暂停页保留急救备用入口。撤去右下重复残敌/急救浮条和常驻自动射击牌。闪避保留64像素按钮，以外圈进度及剩余秒数显示真实冷却。Boss额外占28像素，镜头与出生安全区域同步预留顶部空间。

运行截图见 `artifacts/floating-controls/`，覆盖320×480、360×640、414×896的普通、Boss和减少动态场景。浏览器实际拖动验证了出圈、边缘起拖、闪避与暂停；独立指针回归测试覆盖两种释放顺序和中断路径。急救验证另见 `artifacts/battle-potion/`，实际游戏中确认35→75生命、数量1→0、使用次数+1及刷新保留；满血与耗尽状态覆盖三个视口。使用随机独立测试数据库，未修改用户存档。尚未做手机真机验收。

## 现行实现：割草构筑界面（2026-10-16）

战斗经验条显示本局等级和经验；青色菱形表示可拾取局内能量。升级打开不透明木质/黄铜三选一，背景战斗和所有计时暂停。三张牌分别展示图标、名称、已有阶数或新技能、效果。320×480下三张牌与重选按钮可同时比较；刷新保留原候选。新规则隐藏手动职业能力，保留移动、自动攻击、闪避与交互。

整备保留“角色／职业”双页签。角色页显示武器、护具、饰物的真实库存和研究训练。职业页沿用三武器预览、黄色雨衣人物、主武器及觉醒说明；未满足K0条件不能免费转职，已解锁职业可切换。研究台显示实际余额、训练级数与费用；旧档显示转换说明和预览确认入口。

暂停页显示本局构筑。结算分别写明本局等级重置，以及研究能量、冥币、装备和材料保留。失败不再沿用“全部物资丢失”文案。案件仍明确需要安全撤离。海图保持已确认的长条滚动方案。

## 1. 通用手机画面规范

| 项目 | 定案 |
| --- | --- |
| 窄屏验证 | 320×480、360×640、414×896；桌面版居中于≤480 CSS px宽竖屏区域 |
| 字号/按键 | 正文≥14 CSS px；所有实际触摸目标≥48 CSS px |
| 层级 | 世界背景→角色/NPC/设施→HUD→不透明面板→确认弹窗；面板文字背后不透复杂场景 |
| 动态 | 用户“减少动态”与系统偏好任一开启即关循环雨光/呼吸/步态装饰；保留静态方向、危险、弱点和确认态 |
| 输入 | 游戏按钮不依赖悬停；焦点轮廓清晰；旋转、切后台、弹窗清理所有持有触点 |
| 颜色 | 暖灯处理友好基地，异常海况用冷蓝绿；危险同时用形状/文字/位置，不单靠红色 |

宽屏不扩展成桌面后台。极窄屏压缩装饰并允许滚动，不缩小正文或触摸区。每个游戏文字面板使用足够不透明底色和木/黄铜材质。

## 2. 首页与调查所

逐项审计状态（2026-10-15）：用户已确认新档首页；已有存档沿用自动恢复，进行中调查先暂停。大厅的分区与快捷入口安排正在逐项审计，不因首页确认而自动视为通过。

| 状态 | 画面与主动作 |
| --- | --- |
| 新档 | “雾港调查所”世界场景，开始调查、设置；不出现继续调查 |
| 有暂停调查 | 展示当前地区/波次；继续调查恢复该局；另有返回调查所规则入口 |
| 正常返所 | 多层剖面场景、资源、角色等级；柜台/档案/整备/升级热区和唯一底部出发提灯 |
| 新NPC到访 | 现有联系人/档案位置出现一次性状态标记；不启用上层空白木牌功能 |
| 存储故障 | 不透明错误面板显示最后保存点、重试及导出；不扣资源/补给 |

大厅与战场不同视角。当前已确认背景不可被动态文字烘焙覆盖；热点随同一背景坐标缩放对位。底部四个透明图标仅响应自身，不照亮上层设施。案件可提交标记跟随祝苇，未提交报告跟随顾檀；升级需求使用下层升级工位。

打开或刷新游戏时自动恢复存档：无存档显示首页，有存档恢复大厅、结算或进行中的调查。恢复调查时先显示暂停面板，玩家点击继续后才推进时间；不因刷新新建或清空进度。

## 3. 案件页

先按地区显示案件名、NPC、目标图标、状态、报酬、危险建议。详情明确：要打什么/拾什么/是否Boss、如何撤离、失败损失和报酬。接取与放弃确认先给一句具体改变。自由调查始终可用。

未开放内容显示条件；一项已接取任务指向其他地区只提示该局不推进，不阻挡出发。进行中最多两项；槽位满时直接解释先提交或放弃。临时任务进度在战场页和结算页区分。

## 4. 海图、整备、扩建与转职

世界航图改为从下向上展开的长条地图，不使用缩放模式。底部近岸群岛，向上依次为外海遗迹、沉没深渊和终章禁忌海域。原生纵向滚动处理触摸与滚轮，鼠标可按住地图上下拖动；顶部四个海域入口可快速定位。首尾限制在底图边缘，不加空白边距。每片海域可容纳多个Boss，当前三个包不是完整三关主线。新增地点使用稳定ID和明确的前置报告，不因插入排序改变旧解锁关系。终章区域仍要求后期主线，不能打完现有两名Boss就启程。

环境先依据各处Boss的造型、能力和原著/原创边界，再表现污染。潮汐巨像对应藤壶、钙壳和反常潮线；万眼主祭对应珊瑚、多眼与钟室仪式；克苏鲁化身对应绿渍巨石和异常几何，未确定Boss的深渊只画未知海域。文字、Boss、航线和背景分层，未开放地区允许看档案但不能启程。底栏保留目标、开放状态、档案和启程，属性、案件与补给在档案内。正文≥14像素，触摸区域≥48像素。减少动态时关闭Boss循环装饰，保留静态高亮。

整备采用「角色 / 职业」双页签，默认角色页。角色居中并露出脸，左侧为武器/护具，右侧为饰物/神器；属性放在下方。点击槽位打开底部详情，不用环形菜单。职业页以三件武器切换预览，中央展示同一人物与独立武器，配合职业名、短特点、能力和明确选用按钮，预览不立即切职业。人物底图、护具、武器分层复用；开局穿黄色雨衣，卸下护具展示普通内搭。未实现的饰物/神器标明尚未开放。补给/案件与地点危险保留在出发海图。

v4职业规则仍按以下策划稿执行，当前代码尚未实现等级与转职限制：10级前显示职业外形和能力预览，无转职按钮；10级选定基础职业。30级前显示一次免费改职机会及过期条件；确认时说明武器/能力替换和保留项。30级后基础职业固定，可在已解锁分支间切换。当前武器不兼容时移入包并装备已有基础枪，不销毁。二转与高阶职业按职业树显示已解锁/任务条件，不显示可付费抢开锁。

扩建页先展示立即生效的地区/联系人/案件，再显示200/6/6或1200/20/20费用；材料不足具体列缺口。扩建失败、取消或本地保存错误不扣物。首区报告和首次转职不能藏在付费按钮里。

## 5. 战斗HUD与控件

顶部层顺序：生命/急救数量；`第N/5波`与下一增援倒计时；阶段/案件小标；Boss出现后在最下增加名字/血条/弱点标记。顶部常驻单行约52 px，Boss血条另占一行。角色等级能量用细进度条；升级短飘字不暂停、不遮住目标。

| 控件 | 区域 | 交互 |
| --- | --- | --- |
| 移动摇杆 | 左下，建议112×112 | 左手拖动；独立触点 |
| 自动攻击状态 | 右下靠内，小图标/文字，不超过32×32 | 非按钮，无攻击误触目标 |
| 闪避 | 右下，56×56 | 右手点按，单次消耗冷却 |
| 职业能力 | 闪避上方，56×56 | 未解锁则不显示；无合法目标显示原因且不消费 |
| 交互 | 靠近目标后48×48起 | 文字是“开启/回收/撤离”，不只显示问号 |
| 暂停 | 顶部右侧48×48 | 立刻停整个战斗世界与倒计时 |

波次牌只出现在入波预警时；每批显示来袭边缘方向并保留0.8秒预警。当前波没清时显示“残敌N只”，第五波显示Boss与残敌。重要攻击和交互不被摇杆、技能或屏幕下缘挡住。Boss命中反馈、弱点反馈、被挡子弹反馈各有不同图形。

## 6. 区域地图、暂停与临时档案

暂停时可看全战区、当前位置、信标、掩体、当前波/下波、Boss方向与案件；不提供传送。重开、放弃调查分别写明影响。按“继续”清输入后恢复倒计时。

局内临时档案分类为材料、装备、案件证物、神器部件；每项显示“本次携带/已入库”，不展示容量格。背包无限；自动拾取半径一单位。掉落重叠时图标展开，具名小提示合并，不弹全屏确认。Boss胜利后把已生成掉落汇集在安全返所清单，不统计退散小怪为击杀。

设置有音量、动态效果、操作说明和导出存档。帮助提示“最近可见目标/无视线/未转职”原因与输入动作，首次显示可跳过。无案件、空库存和未开放职业都有下一步说明。

## 7. 四种结算与迁移页面
