# 完整设计评估与验收清单

版本：4.0。日期：2026-10-15。状态：v4.0规则已完整写入专项；策划推荐待用户整体审计。数值为首测基线，不是已验证平衡。规则稿未整体实现；本轮仅实现下述整备界面和雨衣穿脱。

## 1. 本稿定案了什么

本次把以前分散的草案收敛为一条完整首版，并规划后续主线：一个可玩首区、三种一转、六种二转、六种60级高阶版本、三个Boss地区、三套神器、调查所三级、完整委托表，以及新旧存档处理。

当前本地代码已有二维区域围攻、五波、四周刷新、同屏Boss与残敌；升级、装备和基地规则仍是v3原型。设计完成不等于实现完成。任何声称“游戏已支持v4存档、转职、掉落概率或三区内容”都不准确。

## 2. 主要设计选择及理由

| 选择 | 定案 | 解决的问题 |
| --- | --- | --- |
| 无职业期 | 1级基础枪；10级一转；满级60 | 给明确早期目标，达到10级后能继续积累而非溢出被吞 |
| 一转选择 | 10级选定职业；30级前允许一次免费改职，之后固定基础系 | 早期允许纠正体验判断；后期有职业身份，不允许局内换职与刷武器 |
| 高阶路线 | 30级选择两分支之一，60级深化原分支 | 远程自动射击和单技能按钮保持稳定，不做六角色新骨架 |
| 波次 | 5/30/55/80/105秒，残敌跨波；Boss死即胜利 | Boss高潮后不追逐最后一只远程怪 |
| XP | 按行为类型每次实际击杀发放，失败保留 | 不跟角色等级动态同步怪物、不用死亡抹去所有成长 |
| 装备 | 三槽、三地区九模板；固定池，不抽属性词条 | 比较的是明确武器/属性选择，手机页可读，适合单人制作 |
| 神器 | 每区一套三部件；同区Boss第1/3/5次带回保障 | 有收集目标和最迟进展时间，不无限纯随机 |
| 案件/基地 | 两案上限；免费自由调查；三级服务 | 案件不作入场门票，付费扩建有当期可玩收益 |
| 存档 | v4复制迁移，旧源保留；永久与局内分开 | 新旧奖励含义不同，不能原位篡改或重复发奖 |

主要代价是v4参数表较多，且60级远期职业仍是单人开发负担。分阶段实现并用同一动画骨架降低产量，不把所有路线一次性做完。首版不增加更多属性、主职业、材料、地图或主动按钮。

## 3. 数值复核

经验累计公式在 L 级为 `100×(L−1)+12.5×(L−1)×(L−2)`：10级1800、30级13050、60级48675。三地区全击杀每局经验分别为480、1996、6080；首区四次全额为1920，二区约六次全额将累计到30级，三区再约六次达到60级。玩家漏怪/失败会延后；这是经验曲线的预计节奏，不保证固定局数。

按现有112只普通怪全杀、每只2%自然装备，期望2.24件，Boss固定一件；无自然装备约10.4%。神器自然部件均值0.424件/局，但Boss的第1/3/5次成功带回各自保障缺件，最晚第五次凑齐。平均值、概率和保底分别计算，不能把0.424件宣称为每局实际掉落。

一次升级的总伤害倍率上限在60级为2.18倍，生命基础值218；等级越高并非自动承诺能打赢更高Boss。武器地区版本、Boss弱点、装备和主动机制仍要测。没有用纸上DPS替代关卡生存测试。

## 4. 经济复核

首区K0+Q12+Q11收入220冥币/4样本/5零件；首Boss报告另160/5/5。两者合计380/9/10，扣二级扩建200/6/6后余180/3/4。材料箱和装备回收不是必需收入；漏掉报告或没做样本委托的玩家仍可通过重复首区任务获取材料。

二区K2加两个普通案为580/14/14；Base三级1200/20/20在首领报告后还需要普通案件/材料回收。结尾不在玩家缺这笔费用时锁住。费用是单次基地开销，不反复收费开Boss。若试玩显示必须重复同一任务过多，先调案件收益，不提升任意怪物掉落常量。

## 5. 主要风险和处理

- **高波次怪量压垮手机：** 每波预算、攻击出手上限、预警和手机设备帧时间一起测。不能暗中漏刷或延迟波次。
- **强装备让低区失去风险：** 低区仍给收集与案件，但不跟随等级动态涨血。玩法压力由攻击组合和走位承担，不虚增当前波次数。
- **自动射击被最近残敌分走：** Boss弱点开放且可见时优先Boss；其余时间保持合法目标，切换带15%滞后。验证玩家能否看懂目标圈。
- **贯穿枪不跨击杀门槛：** 对照首区10生命；8伤害两发清两怪会输给单发枪。v4定为10伤害、0.60秒，单目标慢、直线双目标快。
- **转职功能骗重复装备：**基础武器每职业只首领一次，不可回收；切职业改变装备而不创建装备。
- **未接Boss任务阻断故事：**首胜报告独立记录，返所免费补交；不会要求再击杀一次。
- **区三区素材与专利：**两个原创Boss和眷属标原创；克苏鲁化身明确游戏改编。美术制作时才做原著具体细节来源审校，不能把未核验造型写成原著事实。
- **保存失败/旧版迁移：**胜负、任务、Boss报告、部件保底使用独立一次性记录；复制迁移前预览并保留旧库。实现要在存档文档对应部分回归。

## 战斗反馈与经验实现复核（2026-10-15）

用户反馈首区一枪一怪、弹丸粗糙且缺少经验条。已将首区普通怪生命调为18/28/38，初始左轮两发击杀近战；三枪试案导致初装敌群积压过快，未采用。保留五波预算112普通怪与原有伤害/预警，配合三类武器各自弹道、间隔、符弹群伤、命中火花与伤血条改善反馈。新增累计能量、等级属性与存档兼容；不实现本次范围外的转职、装备实例或神器。

模型样例：360×640、初装、无职业能力，沿中心半径4/角速度0.6的圆周目标移动（方向归一化，遇掩体按真实碰撞），生命≤60时用一包急救。左轮130.6秒/76生命、符弹132秒/86生命、鱼叉133.7秒/86生命均可胜利。左轮站桩、不补给在59.8秒失败。其他路径存在失败，不宣称胜率；这些是引擎模拟，不代表玩家/真机手感验收。

实际浏览器隔离存档验证了移动射击、击杀能量0→8→26→30、刷新保持26并暂停恢复。320×480、360×640、414×896的HUD、按钮与敌人血条截图位于`artifacts/interface-review/08-combat-growth-*.jpg`。尚未进行手机真机试玩。海图保持用户暂定版本。

## 2026-10-16：Roguelite 首区实现验收

本轮授权由“战斗改为Roguelite、局内等级不保留、升级随机三选一、局外研究/冥币养成”及后续“开始”“你来定吧”确定。完成局内构筑、三职业主武器/觉醒、公共自动技能、研究训练、三个装备槽、确定强化、首次免费转职及旧档显式转换。未将下方历史永久等级、完整高阶职业或神器方案一并实现。海图没有因本轮扩大内容。

- 当前工作区 `npm test`：58项通过；`npm run build` 通过，仍有既有Zod注释与包体提示。新增Roguelite测试覆盖暂停、候选保存、重选、槽位与满阶、觉醒真实攻击、连锁二次伤害、击杀拾取、失败入账去重、重开重置、训练、装备、转职、转换补偿与余额边界。旧规则测试明确使用旧档夹具。
- 浏览器隔离地址完成新建→移动与自动攻击→拾取经验→三选一→刷新保留同一候选→重选扣次→选择技能→主动结束调查。导出落盘数据确认研究44、冥币5、材料及袖珍罗盘保留，`run`已清空。
- 旧档测试样本含500旧能量、37冥币及旧职业能力。转换后为500研究能量、127冥币，原样本/零件另加4/2。导出的转换前备份与输入样本逐字一致。训练后余额480/112，刷新后属性正确保留。

- 修复了长局模拟暴露的Boss生成死局：人物贴近障碍时，大体型寻路的目标格不可占据，旧搜索会一直失败。现在使用邻近可占据目标格，并对三个视口增加回归。主角保持在敌群上层且受击无敌时保持实体不透明，防止被大Boss覆盖。

三份首测脚本采用初始装备、无训练、不额外修改伤害或无敌，执行绕圈、避开危险、靠近安全经验、可用时闪避和使用自带急救。枪手341.75秒、秘仪师367.85秒、猎手333.50秒胜利，均为局内17级；对应首次升级13.25/15.65/13.10秒。另一个带K0的完整脚本枪手339.55秒完成。三选一的人工阅读时间未计入这些战斗秒数；“6～8分钟一局”仍是含选择的体验目标。没有避开危险的贪经验脚本会在中段失败，不能据代表性成功脚本推算通关率。

当前90只是普通敌人同时存活的保护上限；上述成功脚本峰值约10～13只。尚未据此声称90只时的手机帧率或最终割草密度达标。真机手感、长期经济与大规模构筑的平衡仍需后续试玩。现有副本美术包仍为prototype，本轮机制验收不替代完整副本ready验收。
