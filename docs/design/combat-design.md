# 战斗、五波与胜负规则

版本：4.0。日期：2026-10-15。状态：策划定案，待用户审计；数值为首测基线，不等于用户逐项确认或试玩通过。本轮仅完善文档。

操作与伤害以本文件为准；职业技能见[职业](career-design.md)，具体敌人与 Boss 参数见[副本](instance-design.md)。

## 1. 玩家要做的判断

自动射击降低瞄准负担，玩家负责选位置、排敌群、避开预警、使用职业能力和决定是否撤离。战区有绕行、掩体与开阔地；不依靠挂机、随机反向输入或不明扣血制造挑战。

## 2. 输入与动作

| 操作 | 定案 |
| --- | --- |
| 移动 | 左下虚拟摇杆，速度 3.2 单位/秒；斜向归一化，松手即停 |
| 射击 | 360 度自动，无攻击键、朝向限制、普通弹药消耗 |
| 闪避 | 右下按钮，沿当前移动方向；未移动用最近移动方向；时长 0.25 秒，速度 6.5，冷却 1.2 秒，免伤 0.28 秒 |
| 职业能力 | 右侧按钮，10 级转职后出现；施放规则由职业文档定义 |
| 交互 | 靠近 1.2 单位内对象显示具体动作；补给箱点按，提前撤离持续 2 秒 |
| 恢复 | 暂停补给页使用急救包，立即恢复 40；满血不消耗 |
| 键盘 | WASD/方向键移动，空格闪避，Q 能力，E 交互，Esc 暂停；面板打开时按焦点导航 |

闪避可穿过普通怪群，不能穿 Boss、墙体或障碍。受击硬直 0.12 秒，受击后免伤 0.65 秒；不把同一瞬间五个弹丸全部叠在角色身上。多个伤害同批到来，取该批最高一次，进入受击免伤；护盾先吸收，余量再扣生命。

移动、自动射击可同时进行。闪避与受击时不新发普通弹，但已发射的弹继续飞。技能不强迫玩家停步；单触点按技能不偷偷触发闪避。触摸取消、失焦、旋转、切后台和暂停均清除输入，不缓存松手前指令。

## 3. 自动选敌与弹道

合法目标须存活、处于武器射程、当前视口含 0.5 单位边缘内，且不被实体遮挡。一般选择最近目标；距离相同按稳定实体 ID。当前目标仍合法且距离不比新目标远 15% 以上时维持，避免每帧跳动。

Boss 弱点开放、可见且在射程内时优先 Boss，之后恢复上述最近目标。此为 v4 的明确选择，用来解决残敌抢走全部弱点窗口的问题；不穿墙，不向屏外 Boss 盲射。职业技能使用同一合法目标，玩家仍可用移动影响选择。

开火时锁定方向，弹丸不追踪拐弯。每发有唯一命中记录；普通子弹第一次命中结束，贯穿按模板限制命中不同目标，不重复命中同一 Boss 或重叠部件。墙体先阻挡，不能靠溅射隔墙命中；弹丸寿命按射程与速度确定，离开战区回收。

## 4. 全副本时间协议

| 阶段 | 开始秒数 | 总量与批次归属 |
| --- | ---: | --- |
| 第一波 | 5 | 普通怪；首区 16 只 / 4 批 |
| 第二波 | 30 | 普通怪；首区 24 只 / 4 批 |
| 第三波 | 55 | 普通怪；首区 32 只 / 5 批 |
| 第四波 | 80 | 普通怪；首区 40 只 / 5 批 |
| 第五波 | 105 | 唯一所选 Boss |

各区沿用此时间表，三类数量见副本唯一编队表。批间隔依次 6/6/5/5 秒。总量均分，余数按稳定顺序分到前批；每种行为数量也必须精确分配，不能四舍五入漏怪。首区最后一批在 100 秒开始，早于 Boss。

从场景资源加载完、玩家可操作时开始有效计时。时点表示开始预警和生成阶段，普通预警 0.8 秒，完成后实体才可攻击。下一波不等清怪、拾取、任务完成或走到地标。提前清完不提前下一波；每波固定预算，不无限补怪，不生成第六波。

暂停、面板、切后台停止世界、计时、弹道和冷却；恢复不补算现实离线时间。载入恢复同一波、批次和预警剩余时间，不能重复创建波次。慢帧按有效时间补发应到批次，但须完整预警；性能不够应在内容测试中解决，不靠残敌数量暗中推迟波次。

## 5. 出生与攻击公平性

生成点在当前可操作视野四周、距离玩家至少 3 单位，避开障碍、设施碰撞、HUD 遮挡区与不可达地块。贴边时改用其他安全方向，不强行四边各刷一只。位置失效就重选并重新完整预警；只允许短暂等待安全点，不改变波次计数或偷偷删除预算。

Boss 从当前交战区附近显现，预警 1.2 秒，允许出现前调整位置。不能要求玩家到固定终点，不能传送玩家。Boss 屏外只追近、不开始危险蓄力；已发射且有明确来源的弹可继续飞行，并有边缘方向提示。

同屏普通怪最多两只近战处于扑击准备/攻击、两处法术预警、四只远程同时进入射击准备。其他怪继续追踪和占位，不停生成。Boss 预警独立保留安全通道；限制攻击出手密度，不是给玩家永远无伤的怪物。

近战攻击先压身并固定方向，冲刺不在途中追踪转弯；远程子弹可看见；法术先固定落点，不跟脚。普通怪死亡立刻停止新攻击并取消未完成法阵，已发射普通弹仍存在，Boss 胜利统一清除。

## 6. 伤害与弱点

普通伤害 = 武器基础值 × 等级倍率。枪手标记再乘 1.20；同类标记只保留较强一次。Boss 弱点关闭时乘该 Boss 的身体伤害系数，开放时改乘武器弱点倍率，两者不同时乘。通用枪/枪手 1.8、秘仪武器 1.6、鱼叉 2.6。职业技能的特殊系数只在明确位置追加一次。

范围伤害对每个不同目标结算一次；同一 Boss 多部件不是多个目标。护盾不回血，按剩余量吸收，持续结束清除。牵制、减速、打断不作用 Boss，持续伤害和标记伤害正常作用。未发生的视觉碰撞不得先扣血；伤害出现时要有来源与受击反馈。

玩家与 Boss 同一结算批次都生命归零时判失败；玩家仍存活且 Boss 归零才判胜利。经验升级在死亡判定后不复活角色。此规则必须使用固定结算顺序测试，不依赖不同设备的帧率。

## 7. Boss 循环与第二阶段

Boss 追近 → 预警锁定 → 执行 → 恢复并开放弱点 → 下一次。生命首次低于 50% 进入二阶段，显示一次明确提示，取消尚未开始执行的旧预警再给新预警，不瞬间扣血。更密集攻击仍保留可走安全区。

首区两招为三处落点和扇形弹幕；二阶段增加落点和弹道。第二、第三地区使用各自参数与环境身份，不仅染色加血。具体每招数量、伤害、冷却与弱点窗口见副本。

## 8. 胜利、撤离与失败

Boss 死亡后立刻停普通敌人伤害、弹道、法术和待生成批次，残敌退散；未击杀者无经验、任务计数或掉落。已生成掉落与 Boss 奖励汇集，保存为待结算胜利，再安全返所。安全确认不要求继续守住两秒、不强制跑回入口。

Boss 前可以靠近信标保持交互两秒提前撤离；受击、离开范围或松手打断，不扣物品。交互时世界继续，暂停查看路线时停止。只带回已拾取物品，不发未打 Boss 的胜利奖。放弃调查按失败处理，不伪装成安全撤离。

失败免费返所，成长与战利品处理依[存档规则](save-design.md)执行。重新出发从新局五秒准备开始；没有本局原地复活、看广告续命或实时体力。

## 9. 必测场景

不杀怪、快速清场、贴四角、预警中移动、边缘 Boss、无合法目标按技能、群怪与 Boss 同屏、贯穿重叠、多个法阵、暂停恢复、预警重载、同归于尽、胜利后残留弹、提前撤离被打断。分别用新手基础装、同地区常规装、较强装测；站桩不应成为可靠过关方法，合理走位不应依赖稀有掉落。
