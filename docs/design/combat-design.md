# 战斗节奏与胜负规则

## 首区试玩试调 v2（2026-10-16）

用户要求减少重复波次、提高近战怪存在感并重新评估爽感。本轮借鉴[Brotato官方介绍](https://store.steampowered.com/app/1942280/Brotato/)中的20至90秒压力段与成长间隔，及[Vampire Survivors官方介绍](https://store.steampowered.com/app/1794680/Vampire_Survivors/)中的选择驱动滚雪球。对本游戏的推断是：短局需要更密集的变化、可见的成长和明确兑现的胜利。没有照搬对方的完整局长、波数或武器数量。

新开首区割草局采用三个阶段：

| 阶段 | 开始 | 内容 | 增援 |
| --- | --- | --- | --- |
| 进攻一 | 5秒 | 52近战、4远程；其中1只近战精英 | 6批，间隔7秒 |
| 进攻二 | 50秒 | 72近战、14远程、6秘仪；其中1只近战精英 | 6批，间隔8秒 |
| Boss | 100秒 | 潮汐巨像，1200生命 | 单次显现 |

普通近战生命从旧局18试调为28，默认左轮需3发、初始鱼叉需2发；精英为56生命。减少阶段数量，同时维持持续进攻，避免用减少敌人数量制造长空场。精英在第一阶段第5批、第二阶段第4批出现，各提供一次觉醒机会。暂不新增怪物种类或资产。

主武器3阶双发、5阶三发；枪手觉醒保留三发正面并增加侧后弹幕，秘仪师觉醒使用强化单发和连锁爆裂，避免觉醒反而降低单体输出。鱼叉维持贯穿成长与三叉觉醒。提灯范围提高并提供真实命中脉冲；电弧、沉钟冷却分别为1.7和2.8秒。沉钟还会打断普通怪蓄力并推开半格，提供近身解围；Boss只受伤害，不受控制。攻击槽未填满时每次强化提供一个尚未拥有的攻击选择，让构筑形态更早发生变化。

灵魂使用较大的亮青白轮廓、深色底衬与光晕；混合材料掉落也显示灵魂标记。新局在3格内吸附，抵达玩家后才增加经验，隔墙不吸附；拾取音效按80毫秒节流。减少动态效果关闭漂浮，保留静态标记。背景按等比居中裁切覆盖战区，海面延伸也保持同一缩放倍率；碰撞与世界尺寸不变。

Boss每轮在近距离目标与有界追击窗口之间切换，追击后仍会发动攻击，避免无限追逐。击败Boss后立即停止伤害、自动收齐掉落与奖励并进入胜利结算；即使退出请求传入失败也不能覆盖已成立的胜利。胜利旧档加载或导入时自动完成结算，报告和奖励只保存一次。未击败Boss时按钮明确写为“放弃并返所”。

新局标记`pacingVersion:2`；`legacyRogueWaves`和`legacyRogueBossHealth`保留旧进行中割草局的数据。旧永久成长局仍使用原五阶段。没有缩短旧局计时或清除已有进度。

验证：`node scripts/combat-sample.ts`覆盖3职业×2种子，固定绕场、自动选项、低血急救和近身闪避。六个样本战斗计时1分50秒至2分40秒完成（不含三选一思考时间），首次升级17至19秒，Boss前最高同屏16至23只。它只验证输出和节奏假设，不代表真人胜率或已证明好玩。样本与实际浏览器截图在`artifacts/combat-redesign/`；本轮仅完成一次可玩性试调，仍需用户手机反馈。


## 现行实现：海下涌出与近距围攻（2026-10-16）

普通敌群在玩家周围随机选择方位和距离，可在视野内生成，也可在屏幕外生成后走进来。没有固定八向入口或轮换顺序。同一批允许自然集中在某一侧。取点受场地边界、可达性、安全距离及拥挤约束；预警点不会因镜头尺寸变化被搬回屏内，只有玩家贴近或实际位置不安全时才重选并完整预警。镜头以可操作区域居中。首区数量、波次时点和同时存活上限不变。

预警改为海水翻涌与身体逐渐浮出。预警中的形象仍属于pending，不能被攻击，也不能造成伤害；只有倒计时结束才生成追击实体。形象复用已有图集，通过固定水线裁切和上移显示，不冒充新绘逐帧动画。减少动态模式保留静态半浮轮廓、水迹和泡沫。屏外怪物先完成浮出，再沿可走路线追进画面；未进入可见交战区时不会开始蓄力或发动新攻击。Boss首次入场以4.5格为逼近目标，最多持续4秒，随后恢复原有攻击判断，避免永久等待。重载沿用原预警位置、剩余时间及排队状态。

主武器射程见[职业当前实现](career-design.md)。索敌默认读取真实职业射程，弹道有效距离扣除枪口初始偏移。远处无合法目标时不提前攻击。电弧首跳与符阵落点遵守主武器交战距离，后续电弧跳跃距离为2.6格；提灯和回响半径不超过主武器射程。自动技能选敌也受当前可见战区约束。首区附蛰虫攻击距离缩到3.4格，秘仪师缩到3.8格；远程怪在距离外持续追近，进入攻击距离后才蓄力，保留各自攻击类型。

验证：三职业×主武器1/3/5阶，九个30秒站立引擎样本全部存活；初阶末生命40～70，中阶70～90，高阶90～110。样本随机种子为1000＋职业索引×10＋武器阶数；即时选择首个升级候选，不代表手机手感或整局通关率。回归覆盖随机方位、屏内/屏外取点与进入、短射程与弹道、辅助技能、远程追近及预警重载。三个竖屏检查与运行片段在 `artifacts/surround-combat/`。完整局势和真机手感仍需试玩。

## 现行实现：首区割草战斗（2026-10-16）

新规则只改变局内构筑、节奏和首区敌群配置。移动、自动选敌、掩体、四周预警、可选闪避、Boss 弱点与安全撤离继续共用既有战斗系统。职业与公共技能全部自动释放，不再显示手动职业能力按钮。

| 波次 | 开始秒数 | 近战 / 弹道 / 法术 / Boss | 批次与间隔 |
| --- | --- | --- | --- |
| 1 | 8 | 36 / 4 / 0 / 0 | 5批，每10秒 |
| 2 | 70 | 52 / 10 / 2 / 0 | 8批，每8秒 |
| 3 | 140 | 66 / 16 / 6 / 0 | 8批，每8秒 |
| 4 | 210 | 82 / 22 / 8 / 0 | 8批，每8秒 |
| 5 | 280 | 0 / 0 / 0 / 1 | 单个 Boss，生命5000 |

共304只普通敌人，独立于旧档112只、105秒出现Boss的配置。普通敌人最多90只同时存活；拥挤时保留排队预算，获得安全位置后完整预警再生成。排队项不冒充场上危险标记。波次计时不等待清场，Boss不受普通敌人数上限阻挡。

击杀普通敌人留下局内经验，并记录1研究能量。局内经验由收集范围拾取，不直接提升永久等级。每次跨过普通波生存阶段记录5/10/15/25冥币；Boss击杀记录45冥币与40研究能量。合计100冥币，不再重复从掉落金币计一遍。Boss死亡后残敌退散，不为退散敌人发奖励。

低等级以主武器清理少量敌人；强化后可快速击杀普通怪，压力来自连续增援、混合攻击及精英。首测目标为含选择约6～8分钟。完整引擎模拟能检验规则与可完成性，不能证明手机手感或真实通关率；实测记录见[设计审计](design-audit.md)。

## 1. 玩家要做的判断

自动射击降低瞄准负担，玩家负责选位置、排敌群、避开预警、使用职业能力和决定是否撤离。战区有绕行、掩体与开阔地；不依靠挂机、随机反向输入或不明扣血制造挑战。

## 2. 输入与动作

| 操作 | 定案 |
| --- | --- |
| 移动 | 左下虚拟摇杆，速度 3.2 单位/秒；斜向归一化，松手即停 |
| 射击 | 360 度自动，无攻击键、朝向限制、普通弹药消耗 |
| 闪避 | 右下按钮，沿当前移动方向；未移动用最近移动方向；时长 0.25 秒，速度 6.5，冷却 1.2 秒，免伤 0.28 秒 |
| 职业能力 | 右侧按钮，10 级转职后出现；施放规则由职业文档定义 |
| 交互 | 靠近 1.2 单位内对象显示具体动作；补给箱点按，提前撤离持续 2 秒 |
| 恢复 | 暂停补给页使用急救包，立即恢复 40；满血不消耗 |
| 键盘 | WASD/方向键移动，空格闪避，Q 能力，E 交互，Esc 暂停；面板打开时按焦点导航 |

闪避可穿过普通怪群，不能穿 Boss、墙体或障碍。受击硬直 0.12 秒，受击后免伤 0.65 秒；不把同一瞬间五个弹丸全部叠在角色身上。多个伤害同批到来，取该批最高一次，进入受击免伤；护盾先吸收，余量再扣生命。

移动、自动射击可同时进行。闪避与受击时不新发普通弹，但已发射的弹继续飞。技能不强迫玩家停步；单触点按技能不偷偷触发闪避。触摸取消、失焦、旋转、切后台和暂停均清除输入，不缓存松手前指令。

## 3. 自动选敌与弹道

合法目标须存活、处于武器射程、当前视口含 0.5 单位边缘内，且不被实体遮挡。一般选择最近目标；距离相同按稳定实体 ID。当前目标仍合法且距离不比新目标远 15% 以上时维持，避免每帧跳动。

Boss 弱点开放、可见且在射程内时优先 Boss，之后恢复上述最近目标。此为 v4 的明确选择，用来解决残敌抢走全部弱点窗口的问题；不穿墙，不向屏外 Boss 盲射。职业技能使用同一合法目标，玩家仍可用移动影响选择。

开火时锁定方向，弹丸不追踪拐弯。每发有唯一命中记录；普通子弹第一次命中结束，贯穿按模板限制命中不同目标，不重复命中同一 Boss 或重叠部件。墙体先阻挡，不能靠溅射隔墙命中；弹丸寿命按射程与速度确定，离开战区回收。

## 4. 全副本时间协议

| 阶段 | 开始秒数 | 总量与批次归属 |
| --- | ---: | --- |
| 第一波 | 5 | 普通怪；首区 16 只 / 4 批 |
| 第二波 | 30 | 普通怪；首区 24 只 / 4 批 |
| 第三波 | 55 | 普通怪；首区 32 只 / 5 批 |
| 第四波 | 80 | 普通怪；首区 40 只 / 5 批 |
| 第五波 | 105 | 唯一所选 Boss |

各区沿用此时间表，三类数量见副本唯一编队表。批间隔依次 6/6/5/5 秒。总量均分，余数按稳定顺序分到前批；每种行为数量也必须精确分配，不能四舍五入漏怪。首区最后一批在 100 秒开始，早于 Boss。

从场景资源加载完、玩家可操作时开始有效计时。时点表示开始预警和生成阶段，普通预警 0.8 秒，完成后实体才可攻击。下一波不等清怪、拾取、任务完成或走到地标。提前清完不提前下一波；每波固定预算，不无限补怪，不生成第六波。

暂停、面板、切后台停止世界、计时、弹道和冷却；恢复不补算现实离线时间。载入恢复同一波、批次和预警剩余时间，不能重复创建波次。慢帧按有效时间补发应到批次，但须完整预警；性能不够应在内容测试中解决，不靠残敌数量暗中推迟波次。

## 5. 出生与攻击公平性

生成点在当前可操作视野四周、距离玩家至少 3 单位，避开障碍、设施碰撞、HUD 遮挡区与不可达地块。贴边时改用其他安全方向，不强行四边各刷一只。位置失效就重选并重新完整预警；只允许短暂等待安全点，不改变波次计数或偷偷删除预算。

Boss 从当前交战区附近显现，预警 1.2 秒，允许出现前调整位置。不能要求玩家到固定终点，不能传送玩家。Boss 屏外只追近、不开始危险蓄力；已发射且有明确来源的弹可继续飞行，并有边缘方向提示。

同屏普通怪最多两只近战处于扑击准备/攻击、两处法术预警、四只远程同时进入射击准备。其他怪继续追踪和占位，不停生成。Boss 预警独立保留安全通道；限制攻击出手密度，不是给玩家永远无伤的怪物。

近战攻击先压身并固定方向，冲刺不在途中追踪转弯；远程子弹可看见；法术先固定落点，不跟脚。普通怪死亡立刻停止新攻击并取消未完成法阵，已发射普通弹仍存在，Boss 胜利统一清除。

## 6. 伤害与弱点

普通伤害 = 武器基础值 × 等级倍率。枪手标记再乘 1.20；同类标记只保留较强一次。Boss 弱点关闭时乘该 Boss 的身体伤害系数，开放时改乘武器弱点倍率，两者不同时乘。通用枪/枪手 1.8、秘仪武器 1.6、鱼叉 2.6。职业技能的特殊系数只在明确位置追加一次。

范围伤害对每个不同目标结算一次；同一 Boss 多部件不是多个目标。护盾不回血，按剩余量吸收，持续结束清除。牵制、减速、打断不作用 Boss，持续伤害和标记伤害正常作用。未发生的视觉碰撞不得先扣血；伤害出现时要有来源与受击反馈。

玩家与 Boss 同一结算批次都生命归零时判失败；玩家仍存活且 Boss 归零才判胜利。经验升级在死亡判定后不复活角色。此规则必须使用固定结算顺序测试，不依赖不同设备的帧率。

## 7. Boss 循环与第二阶段

Boss 追近 → 预警锁定 → 执行 → 恢复并开放弱点 → 下一次。生命首次低于 50% 进入二阶段，显示一次明确提示，取消尚未开始执行的旧预警再给新预警，不瞬间扣血。更密集攻击仍保留可走安全区。

首区两招为三处落点和扇形弹幕；二阶段增加落点和弹道。第二、第三地区使用各自参数与环境身份，不仅染色加血。具体每招数量、伤害、冷却与弱点窗口见副本。

## 8. 胜利、撤离与失败

Boss 死亡后立刻停普通敌人伤害、弹道、法术和待生成批次，残敌退散；未击杀者无经验、任务计数或掉落。已生成掉落与 Boss 奖励汇集，保存为待结算胜利，再安全返所。安全确认不要求继续守住两秒、不强制跑回入口。

Boss 前可以靠近信标保持交互两秒提前撤离；受击、离开范围或松手打断，不扣物品。交互时世界继续，暂停查看路线时停止。只带回已拾取物品，不发未打 Boss 的胜利奖。放弃调查按失败处理，不伪装成安全撤离。

失败免费返所，成长与战利品处理依[存档规则](save-design.md)执行。重新出发从新局五秒准备开始；没有本局原地复活、看广告续命或实时体力。

## 9. 必测场景

不杀怪、快速清场、贴四角、预警中移动、边缘 Boss、无合法目标按技能、群怪与 Boss 同屏、贯穿重叠、多个法阵、暂停恢复、预警重载、同归于尽、胜利后残留弹、提前撤离被打断。分别用新手基础装、同地区常规装、较强装测；站桩不应成为可靠过关方法，合理走位不应依赖稀有掉落。

## 当前战斗反馈修订（2026-10-15）

用户要求改善子弹、首区一枪一怪和经验条。运行版左轮/符弹/鱼叉间隔为0.36/0.60/0.90秒，弹速12/8/12，鱼叉伤害24，符弹扩散半径0.8。子弹用短曳光、菱形符弹和带尖鱼叉分别表达，保留克制枪口闪光、命中火花和受伤血条。自动射击限定当前可操作视野与视线；弹道沿途细分碰撞，避免快速弹跳过小怪或掩体，溅射不隔墙。以上是当前原型调优，不表示已完成v4所有职业与弱点机制。

首区普通怪生命从10/20/30调为18/28/38；波次16/24/32/40、五波时点与敌人攻击伤害不变。初始左轮击杀近战需要两发。重鱼叉仍允许一击击杀基础近战，以慢装填和对远程/法术怪的多次命中保持职业差异；不追求所有武器每怪固定同样枪数。
