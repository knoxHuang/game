# Triage Labels

技能使用五个固定的内部角色。GitHub Issues 使用以下中文标签。

| 内部角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待评估` | 维护者需要评估任务 |
| `needs-info` | `待补充信息` | 等待报告者补充信息 |
| `ready-for-agent` | `可交给代理` | 规格完整，可交给代理实施 |
| `ready-for-human` | `需人工处理` | 需要人工实施 |
| `wontfix` | `不予处理` | 不会处理该任务 |

技能提到内部角色时，使用表中对应的中文标签。
后续调整命名时，更新“GitHub 标签”列。
