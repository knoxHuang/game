# 雾港调查所

一款面向手机竖屏浏览器的克苏鲁风格 2D 远程动作冒险。玩家选择职业和 Boss 副本、接取案件、在有边界战区调查，并将怪物掉落的证物带回调查所成长。

## 当前实现

- 三种远程职业：异闻枪手、秘仪师、鱼叉猎手。
- 自动射击：360 度锁定最近的可见敌人，不需要按攻击或转向瞄准。
- 雾港沉船区：二维区域围攻、五波定时增援、近战/弹道/法术怪物、独立掩体与撤离信标。
- Boss 副本选择：在纵向世界海图上点选 Boss 像素头像；详情比较角色生命、每秒伤害和推荐值。
- Boss 战：大型像素 Boss、落点预警、弹幕、弱点窗口和 Boss 委托物品掉落。
- 怪物掉落案件物品；失败后角色返回调查所，本次未撤离的物资与任务进度丢失。
- 调查所案件、角色/职业双页签整备、雨衣叠层穿脱、设施扩建、结算与本地存档。
- 新版使用独立 IndexedDB 数据库 `fog-harbor-investigator-v3`。旧版矿洞存档保留在 `abyss-office` 数据库中。

策划方向与后续阶段见 [`docs/design/`](docs/design/game-design.md)。沉没修道院和星蚀裂隙仍未进入当前可玩版本。

## 本地运行

```sh
npm ci
npm run dev
```

构建检查：

```sh
npm run build
```

## 新增副本

副本由 `src/content/dungeons/*.json` 配置。新增包后运行 `npm run content:check`，目录会自动更新，海图、战斗、路线与存档校验共用该目录。构建和启动开发服务前也会执行检查。Node.js 需为24或更新版本。

生成与验收步骤见 [副本生成流程](docs/agents/dungeon-generation.md)。背景、眷属和战斗美术属于副本包，不再分散写在 Boss 专用条件分支中。

```sh
npm run content:check
npm test
npm run build
npm run content:ready -- <副本id>
```

当前三包仍为原型，保留既有内容和存档 ID。其独立小头像、绘图卡、主题图集和场景尚未全部补齐；普通校验允许原型并给出提示，完整交付检查会拒绝未完成的包。自动检查不能替代原著核对和视觉审阅。

当前战斗配置为 schemaVersion 3：五波按 5 / 30 / 55 / 80 / 105 秒触发，四波小怪总量分别16 / 24 / 32 / 40只，波内分批增援，从交战区四周预警生成，第五波为 Boss。残敌跨波保留，胜利后退散。旧 v3 存档保留并兼容转换；等级和转职成长仍未实现。

当前战区由`arena`配置，首区20×24单位；镜头支持水平和垂直跟随，暂停中可查看整体战区地图。旧路段与v2定时调查兼容转换；已开始阶段不会重复补发。
