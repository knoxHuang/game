# 雾港调查所

一款面向手机竖屏浏览器的克苏鲁题材 Roguelite 割草游戏。玩家走位、自动攻击、局内升级三选一，再用研究能量、冥币与装备发展调查所。

## 当前实现

- 三种远程职业：异闻枪手、秘仪师、鱼叉猎手。
- 局内成长：从Lv.1开始，拾取经验后三选一，三攻击/三辅助，12项技能与三种职业觉醒；结算重置局内等级。
- 局外成长：研究训练、武器/护具/饰物、确定装备强化与转职。旧档保留原规则，返所可预览转换并备份。
- 自动射击：360 度锁定最近的可见敌人，不需要按攻击或转向瞄准。
- 雾港沉船区：二维区域围攻、两段进攻加Boss的短局、近战/弹道/法术怪物、独立掩体与撤离信标。
- Boss 副本选择：在可上下拖动的四海域长条航图上预览Boss；各海域可扩展多个地点，按明确前置逐步开放。克苏鲁化身属于后期终章。
- Boss 战：大型像素 Boss、落点预警、弹幕、弱点窗口和 Boss 委托物品掉落。
- 失败保留已获得的研究能量、冥币、装备和材料；案件证据与Boss报告仍需安全撤离。
- 调查所案件、角色/职业双页签整备、黄色雨衣形象、设施扩建、结算与本地存档。旧规则仍支持原护具穿脱。
- 新版使用独立 IndexedDB 数据库 `fog-harbor-investigator-v3`。旧版矿洞存档保留在 `abyss-office` 数据库中。

策划方向与后续阶段见 [`docs/design/`](docs/design/game-design.md)。沉没修道院和星蚀裂隙仍未进入当前可玩版本。

## 本地运行

```sh
npm ci
npm run dev
```

构建检查：

```sh
npm run build
```

## GitHub Pages

手机测试地址：https://knoxhuang.github.io/game/ 。Pages 从 `gh-pages` 分支根目录发布，`master` 保留源码。

运行 `npm run build:pages` 生成 `dist/`，然后将其中的文件发布到 `gh-pages`。该命令同时适配脚本、样式和游戏图片的 `/game/` 路径。

## 新增副本

副本由 `src/content/dungeons/*.json` 配置。新增包后运行 `npm run content:check`，目录会自动更新，海图、战斗、路线与存档校验共用该目录。构建和启动开发服务前也会执行检查。Node.js 需为24或更新版本。

生成与验收步骤见 [副本生成流程](docs/agents/dungeon-generation.md)。背景、眷属和战斗美术属于副本包，不再分散写在 Boss 专用条件分支中。

```sh
npm run content:check
npm test
npm run build
npm run content:ready -- <副本id>
```

当前三包仍为原型，保留既有内容和存档 ID。其独立小头像、绘图卡、主题图集和场景尚未全部补齐；普通校验允许原型并给出提示，完整交付检查会拒绝未完成的包。自动检查不能替代原著核对和视觉审阅。

旧永久成长局的战斗配置保留 schemaVersion 3：五波按 5 / 30 / 55 / 80 / 105 秒触发，四波小怪总量分别16 / 24 / 32 / 40只，波内分批增援，从交战区四周预警生成，第五波为 Boss。残敌跨波保留，胜利后退散。旧 v3 存档保留并兼容转换；等级与经验已接入，转职门槛和高阶职业仍未实现。

当前战区由`arena`配置，首区20×24单位；镜头支持水平和垂直跟随，暂停中可查看整体战区地图。旧路段与v2定时调查兼容转换；已开始阶段不会重复补发。

当前首区新开割草局已试调为5/50/100秒进入两段进攻和Boss，击败后自动胜利结算。旧进行中的割草局保留原五阶段。地图等比裁切，灵魂具备高对比标记与吸附；技能3阶和5阶提供可见形态变化。测量命令：`node scripts/combat-sample.ts`，样本不能代替真人手感。
