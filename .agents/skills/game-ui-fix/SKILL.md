# 界面与交互修复

先执行 [游戏技能共用约定](../../../docs/agents/game-workflow.md)。

## 调查入口

- 读取 [界面设计](../../../docs/design/interface-design.md)、[大厅美术](../../../public/assets/lobby/README.md)、[共用界面美术](../../../public/assets/ui/README.md)，查看 `public/assets/lobby/cutaway-harbor.png`。
- 从 `src/view.ts`、`src/lobby.ts`、`src/main.ts` 的事件路由及相关 CSS 追踪问题。共用材质由 `src/game-ui.css` 管理。

## 排查与修复

1. 记录页面、面板状态、视口和操作方式。实际打开页面，区分布局遮挡、事件未触发、禁用条件和数据未刷新。
2. 检查背景与热点坐标、容器裁切、滚动区、固定操作区、模态层、pointer-events 和多触点归属。按钮调用成功但业务状态错误时，继续读取成长或存档技能。
3. 复用场景入口与共用材质。使用实际状态渲染标记、数量和禁用原因；保留可访问名称与键盘焦点。以原始问题所在层修复，避免用全局缩放压缩正文和触摸区。
4. 在三个规定竖屏尺寸重做原操作。检查至少 48 CSS 像素触摸区、14 CSS 像素正文，以及面板开关、滚动、焦点和两类减少动态效果设置。

## 完成条件

原症状消失，相关入口仍可操作；提供实际运行截图。若错误来自战斗画面的坐标或图集，补充渲染技能的验证。
