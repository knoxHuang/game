# 美术与渲染修复

先执行 [游戏技能共用约定](../../../docs/agents/game-workflow.md)。

## 调查入口

- 读取 [界面设计](../../../docs/design/interface-design.md)、[大厅美术](../../../public/assets/lobby/README.md)、[界面美术](../../../public/assets/ui/README.md)、[游戏美术](../../../public/assets/game/README.md)，查看确认的大厅背景。
- 检查 `src/art.ts`、`src/renderer.ts`、`src/content/visuals.ts`、`src/battle-camera.ts` 及目标包的资源配置。改变副本资产时同时执行 `docs/agents/dungeon-generation.md`。

## 排查与修复

1. 确认实体是否存在于游戏状态，再检查请求、纹理键、实际加载尺寸和透明通道。实体未生成转查内容或战斗，避免先用替代图片遮盖逻辑问题。
2. 对照实际图片检查内容边界、帧号、帧尺寸、锚点、方向、比例和图层。既有共用图集按实际内容区域采样，不假定严格等分。
   人物姿态不自然，或服装、附件叠加出现遮脸、露底、接点错位时，执行[分层服装贴合](../game-art-production/SKILL.md#分层服装贴合)，区分底图姿态、坐标错误与素材形变。
3. 区分静态方向姿态和完整帧动画。检查循环动作、一次性动作末帧、死亡窗口与运行状态是否一致；以当前契约确定字段。
4. 检查镜头边界、屏幕坐标与世界坐标、缩放后热点/碰撞/预警对位。图像轮廓、受击范围和攻击范围分别核实。
5. 修复后在实际游戏中检查受影响状态、三个视口及减少动态效果。保留危险提示和关键交互的静态表达。

## 完成条件

提供实际运行截图；涉及动作时记录动作切换检查。新增或替换资源补记用途与来源；需要重绘时使用美术制作技能。
