# 游戏美术制作与接入

先执行 [游戏技能共用约定](../../../docs/agents/game-workflow.md)。

## 制作依据

读取 [界面设计](../../../docs/design/interface-design.md)、[大厅美术](../../../public/assets/lobby/README.md)、[界面美术](../../../public/assets/ui/README.md) 和 [游戏美术](../../../public/assets/game/README.md)，查看 `public/assets/lobby/cutaway-harbor.png`。人物外形另读角色设计；副本资产执行副本生成流程。

## 制作流程

1. 检查已有资产能否复用，确定用途、显示尺寸、视角、透明要求、轮廓与动画状态。保持黄色雨衣主角及已确认角色识别特征。制作战斗角色、怪物、Boss、场景或特效时，先执行[战斗辨识与提示词](../../../docs/agents/dungeon-generation.md#战斗辨识与提示词)，再分别生成各层资产。
2. 栅格图像生成/编辑使用当前可用的 `imagegen` 技能和工具，先读其说明；工具不可用时完成可安全准备的规格与接入工作，并报告缺失，不把占位图称为最终资产。代码或矢量原生素材按原形式编辑。
3. 同一实体先固定造型再派生头像、卡图、战斗姿态；背景、角色、灯光与交互分层。动态数值和操作文字交给界面层渲染。
4. 将资源放入项目对应运行目录，母图和记录与运行资源分开。记录提示词、参考、工具、来源、导出处理及用途；实际外部素材核实使用许可。副本规格与预算以生成流程为准。
5. 接入实际消费者，检查图集真实内容区域、透明边缘、帧与锚点、比例、像素可读性及小尺寸识别。需要时读取渲染修复技能。
6. 在实际场景和规定竖屏尺寸审阅。按战斗辨识规则检查角色、敌人和背景的同屏区分；检查预警、文字和触摸入口不被美术遮挡。动画分别检查普通模式与减少动态效果。

## 分层服装贴合

1. 先固定一张姿态自然、穿戴完整的母图，检查头颈肩与躯干朝向。内搭和服装共用画布、姿势、比例与脚底锚点；优先从同一母图或可编辑分层源文件派生。
2. 先做领口和双腕的小样。检查下巴与衣领间隙、肩线、袖口包住手腕的遮挡及手指完整度。分别生成的人物和服装存在几何差异时，转用保留坐标的蒙版或像素编辑；按当前工具权限执行，不靠追加提示词重复抽图。
3. 拆层前确认被衣服遮住的身体和内搭由何处补全。母图不包含这些像素；仅把外套抠透明不能得到完整底图。补绘固定在遮挡区域，并同时检查卸衣状态。
4. 接入前检查完整人物、实际显示尺寸及接点放大图。穿戴应保持母图姿态与轮廓，卸衣应无空洞、残留衣片、重复手指或拼接边。像素重组一致只证明重组正确，不能代替两种状态的视觉验收。
5. 仅当全部接点有相同坐标误差时统一校准。多个接点无法同时对齐时修素材；避免分别拉伸衣服宽高。所有消费页面共用叠加规则，再验证穿脱与减少动态效果。
6. 小样仍有同类缺陷，或工具无法保持接点与补绘边界时，保留失败证据，说明所缺源图或编辑能力，停止该轮重生成与接入。报告未通过，待方法或输入发生变化后再继续。

## 完成条件

资产已接入、来源可追溯，交付实际运行截图。仅有母图或概念图不代表完成游戏资产接入。
