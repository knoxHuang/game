# 战斗与操作修复

先执行 [游戏技能共用约定](../../../docs/agents/game-workflow.md)。

## 调查入口

读取 [战斗设计](../../../docs/design/combat-design.md) 和涉及的副本/职业设计。入口为 `src/engine.ts`、`src/battle.ts`、`src/geometry.ts`、`src/main.ts`；检查 `tests/timed-battle.test.ts`、`tests/boss-regression.test.ts` 和 `tests/dungeons.test.ts` 的相关用例。

## 排查与修复

1. 构造能捕获原症状的状态、输入和 delta 序列。隔离时间与随机因素，区分输入未到达、计时未推进、目标不合法与命中未结算。
2. 沿输入 → tick → 生成/攻击/碰撞 → 状态/事件 → 显示追踪。控制行为正确但图像错误时读取渲染技能。
3. 核对全局五波计时与路线移动独立；暂停是否冻结时间；残敌与 Boss 共存；Boss 胜利后的攻击清理和奖励边界。具体时点读取目标包，避免复制文档示例秒数。
4. 自动射击核对射程、视线和最近合法目标；弹道核对初始方向、墙体、伤害与弱点。能力、触摸取消、切后台与开面板检查输入和冷却状态。
5. 在正确调用层补能复现原问题的回归用例，再修复；运行相关测试与构建。涉及输入、镜头或预警时追加实际运行和竖屏检查。

## 完成条件

原始复现场景通过，相关正常与边界流程通过；说明根因及检查结果。跨重载或奖励异常追加存档/成长技能。
