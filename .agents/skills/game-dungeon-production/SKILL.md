# 完整副本制作

先执行 [游戏技能共用约定](../../../docs/agents/game-workflow.md)。

## 执行依据

完整读取并执行 [副本生成流程](../../../docs/agents/dungeon-generation.md)，以 `src/content/schema.ts` 为字段和行为依据。该流程负责来源、资产规格、目录、预算和验收，技能不另存一份规格。

## 制作要点

1. 核对目标身份、原著与改编边界，查看现有目标包和确认美术。神祇本体、化身或眷属首领需与关卡身份一致。
2. 按当前契约建立或扩展包。保留已有稳定 ID；核对全局五波与路线场景分工。文档旧字段与当前契约不符时说明差异，使用支持字段，不降低校验。
3. 先统一轮廓、比例、材质、识别部位和动作，再按美术制作技能生成头像、绘图卡、Boss/眷属图集、独立主题环境、地形与特效。生成前执行流程中的[战斗辨识与提示词](../../../docs/agents/dungeon-generation.md#战斗辨识与提示词)，分别确定背景、黄色雨衣主角和敌人的色彩层次；统一画法，环境服从神祇主题。
4. 若需求超出引擎能力，按明确授权使用功能实现技能扩展契约和消费者；仅配置不能实现的机制不能写成已完成。
5. 执行流程规定的内容校验、测试、构建、实际运行与三尺寸截图。按同一设定审查不同用途图像，实际观察战斗和碰撞。
6. 完整交付运行 `npm run content:ready -- <目标ID>`。只有资源与运行验收成立才标记 ready；阻碍存在则保持真实状态并列出缺失。

## 完成条件

交付可运行目标包、来源记录、完整资源、实际截图和目标 ready 结果。局部修复不强制重新制作全部资产。
