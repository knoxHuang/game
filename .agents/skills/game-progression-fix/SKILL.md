# 案件与成长修复

先执行 [游戏技能共用约定](../../../docs/agents/game-workflow.md)。

## 调查入口

读取本次相关的 [职业成长](../../../docs/design/career-design.md)、[装备掉落](../../../docs/design/equipment-design.md) 和界面设计。检查 `src/model.ts`、`src/engine.ts` 的奖励入口、`src/main.ts` 的 commit/路由和 `src/view.ts` 的展示。

## 排查与修复

1. 列出操作前后状态：永久资源、本局携带、案件进度、已提交、解锁与结算结果。区分数据错误和展示未刷新。
2. 沿击杀/交互 → 获得 → 拾取 → 撤离/失败 → 提交/消耗追踪，找出重复或缺失的状态变化。仅检查当前已实现或本次明确授权的规则。
3. 核对资源不足、重复操作、案件实例、锁定条件、成功/提前撤离/失败的差异。成长和掉落的新失败规则仍需按确认状态处理，不能从旧材料规则推断。
4. 使用操作序列验证奖励只发一次、费用只扣一次、失败操作不改变状态、升级不误改无关进度。跨重载和重试的重复结算读取存档技能。
5. 对原缺陷建立相关回归用例，运行测试与构建；界面变化追加实际操作与截图。

## 完成条件

原始操作和重复/失败路径结果正确，说明采用的规则依据。尚未实现的新成长系统转交功能实现，不以修复名义扩大范围。
