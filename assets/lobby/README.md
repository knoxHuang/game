# 多层调查所大厅美术

以用户最后上传的多层剖面概念图为准。此前室内俯视候选图不作为实现参考。

- `cutaway-harbor.png`：941 × 1672，背景层。保留楼层、NPC、家具、海港与灯光位置。
- `investigator-cutaway.png`：1024 × 1536，带真实透明通道的左向主角层。CSS 用透明内容范围定位，不改原始图片。

来源与制作：使用内置 ImageGen 编辑用户确认的参考图。

背景提示要求：保持指定多层剖面构图；移除标题、资源栏、底部按钮、全部固定文字和中层主角；恢复空白标牌与地面；保留柜台 NPC 和环境灯。生成结果直接存为项目背景。

主角提示要求：只提取参考图中层黄色雨衣调查员；保持向左侧身视角、帽子、背包、枪和靴子；透明背景，全身可见；无文字、界面、地面和其他人物。

图片中的标牌由 HTML 实时标签覆盖。上层望远镜旁木牌保持空白，暂不设置点击热区或高亮；大厅出发统一使用底部提灯。资源、案件提示和工具栏均使用游戏数据，图片中的参考资源数值不进入游戏。

场景位置、主角、灯光、高亮与动画见 `src/lobby.ts` 和 `src/lobby.css`。

## 底部操作美术

按用户后续提供的底部样式参考图替换原任务横条与方形按钮组。

- `brass-tools.png`：1254 × 1254，透明背景的 2 × 2 图标图集。顺序为地图、背包、罗盘、案卷。CSS 按独立边框的内容范围显示，图像外的透明空隙不计入按钮外观。
- `departure-lantern.png`：1145 × 1374，独立透明提灯，保留黄铜、玻璃、火焰和触肢装饰。底部空白铭牌由界面层实时写入“出发”。

使用内置 ImageGen 编辑用户底部参考图。图标提示要求：保留四个独立黄铜边框与像素图案，统一为 2 × 2 网格，移除背景与全部文字。提灯提示要求：保留完整金属装饰与玻璃火焰，只提取右侧提灯，移除铭牌字样、海港、页脚与水印，透明输出。

四个图标保留案件、职业、设置和档案功能；提灯打开 Boss 副本选择。图标名称在悬停或键盘焦点时显示。触摸范围至少 48 CSS 像素。提灯火焰与光晕由独立界面层动画增强，减少动态效果设置仍生效。

底部按钮仅高亮自身，不再联动楼上设施或显示远端动作提示。提灯下移；极窄屏保持与工具图标的点击间距。共用界面面板美术见 `../ui/README.md`。

## 手机加载优化（2026-10-16）

运行资源改用同名无损 WebP，PNG 保留作已确认参考。母图备份与逐项验证见 `art-source/lobby/loading-optimization/compression.json`。使用 `cwebp -lossless -exact -m 6`，四张图片总计从 6,461,499 字节降至 5,039,326 字节，减少 22.0%。Pillow 验证尺寸、全部 RGBA 像素完全一致，透明区域的颜色也不变。

首页预加载大厅背景并赋予高优先级。大厅在图像未完成时显示加载进度；请求失败时提供只重试图像的按钮，不刷新页面或修改存档。

大厅与共用资源在启动进度画面中先加载，进度按实际完成数显示；全部成功后再读取本机存档并进入游戏。大厅局部提示作为后续图片请求失败时的恢复入口。
