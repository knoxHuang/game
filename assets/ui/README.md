# 游戏界面共用美术

`brass-panel.png` 是 1254 × 1254 的旧木黄铜面板。由内置 ImageGen 参考已确认的多层调查所美术生成。

提示要求：单个空白方形九宫格缩放面板；旧黄铜边框、铆钉和克苏鲁触肢角饰；暗色旧木中央区域；精细像素插画；无文字、数值、按钮、人物或示例界面；中央背景完全不透明。

共用样式位于 `src/game-ui.css`，由入口加载。案件、角色整备、升级、档案、设置、海图详情、成功/失败结算、暂停、操作说明和弹窗共用材质、标题字体与按钮反馈。战斗 HUD 使用轻量黄铜边缘，保持预警和弹道可读。

CSS 九宫格边界为 210 像素。新资产尺寸或边框比例变化时，需调整切片边界并检查窄屏角饰和文字对比度。数据文字仍由游戏状态渲染。

物品、装备、案卷、救护包与战斗图像统一从 `../game/` 读取，资源用途和生成提示见该目录的 README。共用面板的鼠标、焦点、按压和禁用态均由 `src/game-ui.css` 控制，避免旧蓝灰按钮覆盖黄铜木质按钮。
